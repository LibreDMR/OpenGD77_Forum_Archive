How old is the radio? This would be clue to the possible hardware version

I don't know about the official firmware, but if you install the wrong version of OpenGD77 the radio will still boot up, but it won't transmit or receive

The official firmware however may not appear to be working as it may be getting confused with the OpenGD77 codeplug data, however I don't recall anyone reporting you symptoms.

Normally all that happens is that the radio asks for a pin code, and you have to reload an official codeplug into the radio to fix this.

Check if the official CPS is able to upload a codeplug.
Note to bypass the pin number think , IIRC you need to change the official CPS's .ini file and make sure the password entry is set to password
Google for the exact details of the .ini file thing



PS.

I find it hard to believe that someone would prefer the stock firmware, unless they need SMS
