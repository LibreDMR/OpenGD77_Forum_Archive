Who wrote the MCD-1200 code ?

I had a look at the source code zip file, and there are muliple things which look strange with the void Read_voice_data() function

Most of the variables are declared as local static, which seems to be unncessary, in fact declaring local variables as static is generally not a good idea in code that uses a RTOS as this makes the compiler add lots of extra code to make the function re-entrant.

Also, all these variables are being used before they are initialised

static volatile uint8_t reg_0x030;
static volatile uint8_t reg_0x031;
static volatile uint8_t reg_0x230;
static volatile uint8_t reg_0x231;


I presume that these variables may need to be global, if the values of these registers from the previous run of the function appear to be needed to determine flow through the Read_voice_data() function.

It looks like the C6000 is using a 'double buffer' system, but the method to detect which buffer to use, looks strange.
