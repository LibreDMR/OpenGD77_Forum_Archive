New MD-2017/RT-82 Beta version 2025 02 15.

Post by F1RMB » Sat Feb 15, 2025 8:57 am

  • Use double height font in uiCPS and Hotspot screens, if enabled.
  • Adds zero VOX tail value (1ms in fact), needed for some packet radio setups.
  • Add APRS Tx Power setting (defaulted to Master).
    • see "Ch Power" in "APRS options"
  • Fix a GPS problem when entering/leaving the Hotspot mode.
  • As usual, some cleanups.
The firmwares are available at: https://drive.proton.me/urls/07MQY7803C#fV9bWbOQk0jZ
The voice prompts are available at: https://drive.proton.me/urls/H0XNJZFH08#YPSZxRlhHBGG

NOTE: You need to use a CPS version greater or equal the the 2025/01/26. See the CPS section viewforum.php?f=12

For translators, the on-screen texts, voice prompts CSV and CPS XML files are located at: https://drive.proton.me/urls/256SP2W1NM#mC9d2L32MEmb
The voice-prompts and localization files have not changed since the last beta.
