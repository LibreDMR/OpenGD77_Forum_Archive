OK

I think there are some other bugs which can occur when operators don't setup the Contact for a Channel, or for the VFO channel (in the CPS)

In these cases the firmware will be using TG 9, but it should be using the first Contact in the Digital Contacts

I am modifying the firmware, so that if the Contact is not defined for a Channel.. When it is loaded from the codeplug memory, the Contact for the Channel will be set to Contact number 1, as the CPS guarantees there is always 1 digital contact as it can not be removed.
