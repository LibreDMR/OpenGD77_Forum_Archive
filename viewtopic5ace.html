DC7SU wrote: ↑
Sun Nov 10, 2024 9:02 pm
 Thank you Lars,
well I allready miss the handling and convenience of openGD77. Can we support Alex DL4LEX in any way for SMS implementation?
We would be happy to incorporate SMS code into the firmware, as long as it is bug free and does not affect the existing functionality.

FYI.

We did try to encorporate the Hotspot SMS passthrough code from Alex, but somehow it affected some voice comms, so we had to remove that code again, and no one has since had time to debug why the hotspot SMS code broke the normal voice handling code.


Hence any submission would need to be thoroughly tested by the author first, as its a pain in the ass for us to remove code and re-release when there are bugs
