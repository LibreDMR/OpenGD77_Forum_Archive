YO3IDG wrote: ↑
Sat Dec 07, 2024 9:01 pm
 One thing I found in the menu, there is an entry for 220MHz squelch, this radio does not have support for that band, can it be removed?
The AT1846S RF chip used in this radio does support 220MHz. Hence why there is a squelch setting for it..

All the OpenGD77 compatible handheld radios use the same chip.

However the MD9600 mobile radio does use the same chip, and does not support 220Mhz, hence it does not have the 220MHz squelch option
