New MD-UV380/RT-3S/DM-1701/RT-84 Beta version 2025 02 23.

Post by F1RMB » Sun Feb 23, 2025 12:13 pm

  • Add audio amp mute feature:
    • When the audio mute is enabled, the radio mode (FM/DMR) font is stroked.
    • Add "Mute: On/Off" in quick menus.
    • Use longpress '0' key for audio mute toggling.
  • Some internal cleanups.
The firmwares are available at: https://drive.proton.me/urls/HTQT39G8G4#xR0c3xPLGvUQ
The voice prompts are available at: https://drive.proton.me/urls/D3JKT50X7M#Md1OQqCWViCJ

NOTE: You need to use a CPS version greater or equal the the 2025/01/26. See the CPS section viewforum.php?f=12

For translators, the on-screen texts, voice prompts CSV are located at: https://drive.proton.me/urls/K6NBA7FRH0#owtc56LE34hj

But it works like this, minus the fact that the firmware don't care about GPS fix losing, but a GPS fix is mandatory to perform continuous zone sorting.

You're defining a Roaming distance (5/10/20km), so if the last position where the channel list was sorted exceeds this distance, a new sort is performed, and the closest channel is selected.

That's the "donor file" that is needed for DMR support.
The OpenGD77 part is delivered in OpenDM1701.zip

You should select the donor file first in the firmware loader and CPS will remember the location.
After that you specify the open firmware and the loading will start.

Donor software:
https://www.passion-radio.com/index.php ... chment=760
(Use MD9600-CSV(2571V5)-V26.45.bin as donor for all radio types above)
