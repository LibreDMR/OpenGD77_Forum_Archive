A few things to check

1. Is you radio in DFU mode?
2. When you plug the cable is there any change in the Windows device managed ?
i.e If you have the wrong cable for the radio, Windows normaly displays a message to indicate a USB problem.
If nothing happens when you plug in the USB cable, then something is very broken, i..e the radio or the cable.
