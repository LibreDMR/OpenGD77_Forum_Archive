433.999765 FMN ( -0.235 kHz )

I had a look in the code and a hack was applied to the UV380 code where it always adds 3kHz for Tx

We don't know why this was needed for the UV380, and we use code in the MD2017

I thought this may be something to do with the undocumted register 0x05, as this needs different values for DMR and FM, which seems to disable audio filtering.
But I just did some tests and changing this register doesn't make any difference.

The problem seems to be that 25kHz FM is 3kHz too low

DMR and FMN seem to be on the same frequency, which is the same frequency I observe on my other radios e.g. my GD77 etc

Anyway. At the moment I can't see why 25kHz FM is 3kHz lower than the other frequencies but I agree that its definietly happening

I'll need to compare the settings between Alpha 1 and Alpha 2 because I can see that its only Alpha 2 that has this problem.
