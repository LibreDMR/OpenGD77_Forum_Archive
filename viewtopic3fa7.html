The best tutorial is from Roger, viewtopic.php?f=19&t=2380

You can skip the first part, which involves the original CPS.

The procedure is almost the same as flashing RD-5R.
The difference are.
1.Make sure you select correct “radio type” in the CPS menu.
2.different donor file. Dm-1701 use donor file from MD-9600.
3.Dm-1701 use different driver in the flashing process. This driver called “STM32 in DFU mode” People have reported many issue about this driver fighting with windows, especially windows 11.
4.you will need openDm1701.zip (not openRD-5R).
5.to put the radio in dfu mode for upgrade the firmware, you need to hold PTT and the button above it while turn the radio on. The LED on the radio will flashing red and green

Just the details that differ, the main idea is the same.

The driver problem with newer radio. In the CPS menu radio type, you will see two group of radio the first one are radios that use MK22 CPU (GD77, RD-5R, 1801) the second group are the radios that use STM32 CPU. This newer radio type share the same STM32 in DFU mode driver.
