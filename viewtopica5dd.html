New Beta 2023 08 09

Post by VK3KYY » Wed Aug 09, 2023 11:20 am

A new beta is available

downloads/GD77/8aefb8db5673f933c940e247c94086fc2ec89bbf
downloads/GD77/Latest

Changes in this version. Note GD77 does not have GPS screen, so these changes to not apply.

• New GPS direction and speed etc screen (F1RMB)
• Turkish language update.
• Beep instead of voice prompt when GPS had fix, when voice prompts are not enabled (F1RMB)
• Tx Frequency offset function in the Channel details screen, By pressing Left / Right button on the Tx frequency (F1RMB)
• UV380 rotary control debouncing (F1RMB)
• Improve GPS NMEA data decoding (F1RMB)
• Various other GPS screen fixes (F1RMB)
• Improve Voice prompts on GPS screen (F1RMB)
• Fix MD-9600 scanning problems. Rotary control restarts scan on paused channel, Up arrow sets currently paused channel as nuisance (F1RMB)
• Remove space characters from font data to save program memory space (F1RMB)
• Fix sunrise and sunset calculations, for use with the Day / Night theme (F1RMB)
• Fixes to Auto Night functionality (F1RMB)
• Fix –W+ power setting on Satellite screen (F1RMB)
• Automatically update realtime clock from GPS (F1RMB)
• Fix PIN code display when no theme is available (F1RMB)
• FM APRS Tx. Quick press SK1 while transmitting on FM - see also the new CPS (VK3KYY)
For details of the FM APRS functionality, see viewtopic.php?f=5&t=3120

We will update the User Guide with these new features soon.

Thanks to Daniel F1RMB for all his work on this release and also thanks to Colin G4EML for answering my technical questions about the C6000 chip


IMPORTANT

Anyone with any existing Emergency System data in the APRS section , needs to delete that data, otherwise the APRS Tx will not work.

VK3KYY-6 audio level = 98(27/15)   [NONE]   __|||||__

 source  VK3KYY  6 c/r=0 res=3 last=0
 digi 1  WIDE2   1   h=0 res=3 last=1
  000:  82 a0 9c 60 60 60 60 ac 96 66 96 b2 b2 6c ae 92  ...````..f...l..
  010:  88 8a 64 40 63 03 f0 21 33 37 35 39 2e 39 39 53  ..d@c..!3759.99S
  020:  5c 31 34 35 30 36 2e 30 30 45 21 20 4f 70 65 6e  \14506.00E! Open
  030:  47 44 37 37                                      GD77

"77" in comment looks like it might be a CTCSS tone in non-standard format.
For most systems to recognize it, use exactly this form "T077" at near beginning of comment, after any frequency.
Position, Emergency!, Network nodes, digis, etc
S 37 59.9900, E 145 06.0000, PL 77.0
 OpenGD77

Can you receive any other APRS transmissions
Also, you may need to open your squelch, some radios the squelch does not open fast enough
