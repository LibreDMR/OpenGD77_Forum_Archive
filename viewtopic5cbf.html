 There appears to be another bug, this one involving the Color Code. R2023.05.08.01 properly exported the color code field to CSV but the latest, and previous release, write a zero to the Color Code column when you exports to CSV.
The problem was that the export function was reading the Rx CC value from the Channel data not the Tx CC.

The firmware only ever used the Tx CC, and the Rx CC byte got re-used for the Lat/Lon in the last release

This is only a problem in the CPS in the Export / Import to CSV and is fixed in the next release
