TS1_2=2; TS2_3=2263
Does not look correct, but I don't know whether that would cause problems

Normally the default TS are defined as

TS1_1=2;
TS2_1=2263;

i.e. the nomenclature for this is

TSx i.e the TS number TS1 or TS2

Followed by a number which indicates the index which starts with 1

See

https://vkdmr.com/connect-your-hotspot/

You can define multiple TGs per TS e.g

TS1_1=5;TS1_2=3801;TS1_3=3802;

This tells IPSC to create static routes for inbound traffic on TG5, TG3801 and TG3802 for TS1


I recommdend you check your codeplug and also your hotspot configuation, becuase the values you are currently using are defintely sub optimal and may not even work.

BTW.

Make sure you have not enabled TA Tx for the channel, as DMR MARC / DMR+ / IPSC2 does not support in-call data and it causes problems if you enable it, even though Talker Alias is defined in the ETSI DMR specification.
The problem is that IPSC (Motorola) is a proprietary and partially not fully ETSI standard compliant.
