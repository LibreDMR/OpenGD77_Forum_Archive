New OpenGD77 CPS 2024 10 20

Post by VK3KYY » Sun Oct 20, 2024 6:27 am

A new version of the OpenGD77CPS is now available

downloads/PC_CPS/Latest

downloads/PC_CPS/Latest/OpenGD77CPSInst ... .20.01.exe


This version fixes a bug on the DMR ID download screen, where the app would crash if the user entered their own separator character.

The CPS has now been changed so that the list of separators is not editable, and code added to detect if an edited separator character had been saved
