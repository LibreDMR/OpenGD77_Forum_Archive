As described in the installation instructions you must always select the file 'MD9600-CSV(2571V5)-V26.45.bin' regardless of which radio version you are using. Only this file will work with the upload process. The exact file is required because we need to extract the DMR codec from it. It is not used for anything else.

The correct file can be downloaded from here https://www.passion-radio.com/index.php ... chment=760

Post by G4EML » Fri Jan 13, 2023 1:13 am

That is correct. The DMO (Direct Mode) ETSI standard only supports one transmission per frequency. There is no timeslot information included in the signal. So whichever timeslot you select the transmission is the same. Timeslot selection is only valid when in RMO (Repeater Mode).

There is an advanced mode called DCDM (Dual capacity direct mode) which does include timeslot information and allows two transmissions per frequency. However the OpenGD77 firmware does not support this mode which is rarely used in amateur radio.

Colin G4EML
