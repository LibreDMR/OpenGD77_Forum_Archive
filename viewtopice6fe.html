Channel information not saved for both channel modes.

Posted: Fri Apr 18, 2025 9:26 am
by MM7FEE
I don't know if this is a bug or a feature request...

Using the latest CPS, if you fill in both analog and digital channel parameters into a CSV file only the parameters associated with the channel type are imported. For example I have many multimode repeaters around me. It is useful to be able to switch from digital to FM to use the repeater in either mode. For this to work you need to store both the digital parameters (CC, TS, etc) and the analog parameters (CTCSS). This can be set on the radio and saved to the codeplug on the radio. You can easily switch between FM and Digital mode. However you cannot set this via the CPS software. It will only allow you to set one or the other. This forces me to take the extra annoying step of having to manually edit all mixed mode channels on the radio every time I adjust something using the CPS.

Request: 1. Allow the CPS to import both analog and digital parameters from a CSV. 2. Allow CPS to set both analog and digital parameters and transfer this to the radio.
