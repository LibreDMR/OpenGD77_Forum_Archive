"Prompt" to "Silent" disables all audio signalling options

  • Quote

Post by DL1GG » Sat Jun 03, 2023 1:19 pm

This is not about voice prompts, but about beep prompts. I hope that it's okay to put that in here anyways.

I like the "Talker" signalling option as it has the valuable "heads up" effect if some activity arises, but I don't want to have the keypad/input/feedback beeps at the same time. But if you switch "Prompt" to "Silent" you have no more audible signalling at all unfortunately. All other signalling options in the "Sound options" menu then switch to "N/A".

It might be a good idea, to separate the ideas of having keypad/input/feedback prompt beeps from the other valuable signalling beeps.

Even the manual says for the Prompt/Silent option "The radio does not provide any audio feedback to button". So the scope of the option seem to be the feedback part only and that whole manual section doesn't say, that you'll lose all audible event signalling, if you go for silent prompting.

Any thought on that?


Besides that, have a nice weekend you all!

Prompt option can be read as "Audio Assist" (what is was long ago, before voice support).
So, if you want it silent, you got it .
About the beep option, at the moment beeps are enable, all beeps. Soon, key beeps and all other beeps will be 2 separate options (and to be clear for people who asked about beeps craziness, there won't be any more settings/granularity about beeps).
