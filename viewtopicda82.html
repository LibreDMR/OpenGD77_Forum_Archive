Thank you, the vocoder code has fixed addresses, when the firmware is launched it transfers this code from flash to IRAM, since the code works faster there, I realized that I need to deal with the linker script and do something like this:

Code: Select all

    .init_array :
    {
    . = ABSOLUTE(0x17000) ;
    *(.codec_bin_section_1)
    KEEP (*(.init_array*))
    . = ALIGN(0x4) ;
    } > REGION_TEXTINRAM
and already in the source code add:

Code: Select all

__attribute__((section(".init_array"))) uint8_t Codec[15000];
something like this

void radioPowerOn(void)
