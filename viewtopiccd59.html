Post by ZL2MGS » Thu Mar 06, 2025 4:33 am

These radios only have one receiver, so it would not be possible to implement a true dual watch - what DW does with the VFOs is switch rapidly between the two channels set on the VFOs.

You could achieve the same with memory channels by setting up a zone with just the two (or three, or four) channels you want to watch in it and start a scan on that zone. Note: a channel can be in more than one zone, so you don't need to recreate existing channels just to do this, you only need to create a "dual watch' zone. You could even have several channels in this zone and use the "zone skip" setting from the HT channel menu to select which ones you want to watch at any given time.
