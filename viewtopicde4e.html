The firmware you downloaded and used for the donor file for OpenGD77 (V26.45.bin) should work on that radio. Any TYT firmware starting V2..... Should work with a V5 radio.

TYT numbering convention...

V0x.xx is for V1 , V2 and V3 radios. (All have identical chipset)
V1x.xx is for V4 radios. (Different synthesiser chip)
V2x.xx is for V5 radios. (Different synthesiser and IF chips)

Colin G4EML
