I hope I haven’t missed something here as I’m pretty thorough at researching before troubling other people. Anyway, here goes. I’ve carried out OP-GD updates on several radios countless times without any troubles apart from “Beta / Test” versions where I expect issues etc. However, my trouble today is. I’ve been handed a TYT UV-380 with the colour screen. It had already been updated with OP-GD v12.12.2023 by a previous owner. I then noticed that the buttons weren’t configured to standard for OP-GD. I decided to upgrade the firmware to the latest test version (v23-03-2025). I’ve used this in my Baofeng 1701’s for evaluation with no side effects for me. After updating this TYT, I discovered the keys / buttons were indeed still wrong. The # key is now the Green Menu Key, Keys 5 & 8 is now up & down arrows, and button 9 is the Red key. I’ve looked intensively for a solution but drawn a blank regarding this. I decided to return the radio to its original TYT Firmware to check the key functionality, and it was perfect with all keys doing what they should. I did stumble across some information on here regarding previous button mapping issues with SK1 & various other issues between the 1701 & TYT but wasn’t sure if this is still a work in progress or just applies to certain radio characteristics being different in production etc. Is there a specific version of OP-GD for this model, or is just an anomaly with this unit. Just a pointer, when I try to read the calibration data on this TYT, it reads but doesn’t display on the PC screen. It just brings up the save file dialogue box. All my other radios display perfect. Sorry to waffle on but any help on this would be greatly appreciated.
