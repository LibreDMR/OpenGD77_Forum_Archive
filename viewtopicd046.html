EA5SW wrote: ↑
Sat Feb 03, 2024 9:31 am
 Another test is return to stock firmware, test and go again to OpenGD77....
Yes. Please test with the stock firmware to see if the speaker in the mic works OK.

Looking in the pin list, there is an unknown input signal on PC3. So if the speaker does work when using the official firmware, then possibly pin PC3 is a sense input that needs to be used to change some other audio configuation in the radio.

However, the only 2 signals I know about the speaker are

SPK_MUTE PB8 Speaker mute
AUDIO_AMP_EN PB9 Audio amplifier power enable

And there are no other unused CPU/MCU pins which could control an audio path to the speaker mic


PS. You probably know but, but for the stock CPS, you need to change in setting.ini file

password=0

to

password=password

Otherwise it will not let you reload the stock codeplug into the radio or will ask for a password
