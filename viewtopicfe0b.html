A very much work in progress UK/EI code plug showing DMR/ANALOGUE repeaters only, enjoy.

To answer a number of questions, this code plug is primarly been setup for use with my MD9600s/RT90s mobile radio and Radiodity GD-77(with GPS) and DM 1701(with GPS), but will work on any other radio that the OpenGD77 firmware has been installed on.

## Latest code plug added ##

Below is the link to the OpenGD77 defind radio operation details, don`t be deterd by the amount of info, it will all make sense as you work your way through it. Enjoy.

https://github.com/LibreDMR/OpenGD77_Us ... r_Guide.md

Today (10 OCT 2024) I have added a modified version of the code plug to enable use of the latest Firmware upgrade that has been released today, for those users with the MD9600+GPS and RT90+GPS, this will give you a insight as to how it works, please remember this is very much in development, and I will be releasing a much modified version in due course.

##IMPORTANT## PLEASE READ THE INFO SUPPLIED IN THE LINK BELOW BEFORE TRYING ANY INSTALLATION##
