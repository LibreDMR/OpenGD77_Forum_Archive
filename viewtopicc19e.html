MD-9600 TX audio distortion on FM 25 KHz mode.

Posted: Mon Apr 21, 2025 4:55 pm
by SP9TA
Hello. I'm a fairly new MD-9600 owner and I don't know if it's a hardware or software problem, but I hope it's software. I don't have the original firmware anymore, so I have no way to check if this was the case. I may have uploaded the incorrect version of OpenGD, as I don't have the markings on the board, and uploaded 2025 03 23 V5, which seems to work.
Correspondents have noticed unpleasant interference on my voice on the 2m band in FM 25 kHz mode. In FM 12.5 kHz mode it is ok. I checked this by recording my voice via RTL-SDR and GQRX and this was indeed confirmed. I connected a function generator in place of the microphone capsule and started testing. I noticed that the problem occurs with sounds above 1430 Hz when we overdrive the signal a little. When speaking into the microphone it is quite easy to overdrive the sibilants, because the pre-emphasis boosts the high notes a lot. In practice, the FM 25 kHz mode is thus useless. It is possible to work in the 12.5 kHz mode, but if the correspondents work in 25 kHz mode and I work in the 12.5 kHz mode, the squelch sometimes closes and cuts out the sound despite the strong signal of the correspondent, so it would be nice if the 25 kHz mode worked after all.
I have been testing on 144.525 MHz, and have determined that:
- The distortion effect only occurs in 25 kHz mode and above 1430 Hz, nothing strange happens in 12.5 mode when the signal is very heavily overdriven (700mV Vpp at mic capsule), the same below this magic frequency of 1430 Hz, also a heavily overdriven signal can be fed, and it will only be clipped without additional distortion.
- The distortion 1570 Hz sinewave waveform looks like this:

The two signals differ by 1 mV Vpp at the microphone capsule terminals, sinusoidal frequency 1570 Hz. The upper graph is after the signal has exceeded the level at which the distortion occurs, the lower one before the exceedance. On lower only deviation clipping occurs, which looks correct.
This is a waveform of a recording made with RTL-SDR and GQRX of an FM demodulated signal without deemphasis or filtering.
To me it looks like some variable in the DSP processing is overflowing when calculating the preemphasis.
- The higher the frequency, e.g. 2 kHz, the easier the effect is to achieve.

At 2.5 kHz there is only a 4.6 dB headroom, from clipping the signal to the occurrence of additional distortion. For the other frequencies I have not measured exactly, as this is difficult for me to measure and takes a lot of time, but if it is necessary I can do so.
In addition, when I set the FM mic in Sound Options to: -6 dB, then, in order to achieve the distortion effect, I have to amplify the signals those 6 dB stronger.
I hope this is not a hardware problem, but some software problem that can be solved.
Thank you.
