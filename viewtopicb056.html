A Release Candidate 1 version of the firmware is now available.

This version will hopefully become the stable Release version for this half of the year.

There are no functional changes between this version and the last Beta.
The only changes were that some redundant code has been removed by Daniel F1RMB and that the development environment, compiler and SDK has been updated to the latest version.
