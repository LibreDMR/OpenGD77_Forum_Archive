Post by G4EML » Tue Dec 26, 2023 1:00 pm

It does not matter what firmware is loaded to your radio. The merge is done in the CPS before it is downloaded and this only works with the stated firmware version. You never need to load that version into your radio, it is only needed by the CPS.

If you follow the installation procedures completely, Including making a flash backup, you should be able to return to the original firmware. People have done this before. However this is not guaranteed, it is one of the small risks you take when loading unofficial firmware. It is up to you if you want to take that risk.
