New OpenGD77 CPS 2025 01 19

Posted: Sun Jan 19, 2025 11:46 am
by F1RMB
  • Cleanup APRS config TX frequency thing.
    • Adds APRS config Transmit QSY Info support flag.
    • Moves the Channel/VFO APRS config dropdown widget out of the Analog group, as now it could be used in Digital too (and FW can do that now).
    • Fix all APRS labels strings (many old "emergency" names there).
  • Adds APRS's TX Frequency and Transmit QSY to CSV import/export.
  • Update Language files for Transmit QSY Info.
  • Enable TxTone in Channel and VFO form if the selected APRS config has a TxFrequency set.
  • Add version number in AboutForm.
The installer can be downloaded from: https://drive.proton.me/urls/A5Q628WGPM#G7nhJfyZ8yCk

NOTE: because the APRS configuration structure has changed a bit, you need a firmware greater or equal to the 2025/01/19 release date.

Because Roger is busy on other stuff, the download location is temporary set to my Proton Drive.
