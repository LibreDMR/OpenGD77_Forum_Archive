  • Quote

Post by VK3KYY » Tue Oct 22, 2024 1:07 am

A new version of the OpenGD77 CPS is now available

downloads/PC_CPS/Latest/OpenGD77CPSInst ... .22.01.exe

downloads/PC_CPS/Latest

This version fixes a problem on the DMR ID download screen where the region number may not be the region of the user because the CPS uses the users own DMR ID as the basis for the region ID and this only worked for user DMR IDs which were 6 or more digits long. i.e People who registered their DMR ID many years ago and who had lower numbers would have seen this bug.

The CPS now defaults to using the first three digits of the users own DMR ID, and this works even there are less than 6 digits in that number.

Obviously if the users own DMR ID is not entered correctly, the region will be incorrect and the CPS will set this value to being empty, which will cause the entire DMR ID database to be used , i.e unfiltered


Additionally in this version, if the user changes the region number the CPS will remember the number they entered

And also, the region can now be a list of numbers separated by commas. So for example, Italian operators should use

222,223,224

as the region, and this will filter for all Italian DMR IDs


Also, as part of these changes, the time taken by the CPS to process and filter the DMIR ID's after the database has been downloaded, has also been reduced.


Note.
The list of regions does not work with the HamDigital download option, because HamDigital doesn't support filtering by more than one region at a time.

Possibly the CPS could be changed so that it doesn't send the region ID to HamDigital and does the filtering inside the CPS, like the other datasets, but I've not invesigated whether this would be practical
