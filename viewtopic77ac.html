So, I just tried with your codeplug, and the same firmware version, and it works as expected.
I'm not sure if you understood how roaming works.
If you're static (e.g, not really moving), you should NOT define a distance in the "Roaming" option (the one in the QuickMenu settings), but manual instead.
Reason is, the re-sorting of the zone will only happen if you moved by, at least, that distance since the last sorting.
On the other hand, using "Roaming: Manual" will re-trigger a zone sorting, each time you validate that option (I mean, pressing GREEN button while it's selected).
Of course, your transceiver location has to be properly set (using GPS or manually enterred) to make it working.
