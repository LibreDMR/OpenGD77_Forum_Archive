Hi. First query.

I have a Baofeng DM1701 flashed with OpenGD77. My (Windows 10) PC has a number of USB ports. In one of them (call it "A"), I plug the radio and the PC says "Device not Recognised". Device Manager says "Unknown USB Device (Device Descriptor Request Failed)". I plug into another (call it "B") and W10 has no issues: it creates a new COM port.

The port A issue, I don't understand, but with respect to port B, if I then fire up the OpenGD77 CPS, and try to flash the codeplug, it makes me select a COM port. It's annoying, but fair enough. It then makes me select the COM port again, and from that point it works fine.

Why do I have to select the COM port twice? This is repeatable.

This had been working fine. The only thing I can think of that changed was that I installed the Retevis CPS and it may have changed the driver.

I don't an on using the Retevis software, so if any solution involves uninstalling it ... no big deal.

Thanks.

 Why do I have to select the COM port twice?
AFIK, this is something strange associated with Windows installing a driver per USB port.

Normally once a driver is installed on one port, Windows will automatically install it again onto a different product is plugged in, but in your case this doesn't seem to be happening.

You could try selecting the non-functioning port in the device manager and manually loading the driver files.
