New MD-UV380/RT-3S/DM-1701/RT-84 Beta version 2025 02 07

Post by F1RMB » Fri Feb 07, 2025 4:06 pm

  • In DMR mode, clear the LC data after an APRS beaconing to avoid handling incomplete data (wrong IDs and so on).
  • Fix APRS QSY: RX and TX freqs were swapped.
The firmwares are available at: https://drive.proton.me/urls/YYAB3S3P9M#Xd1FR6VCxFdT
The voice prompts are available at: https://drive.proton.me/urls/H0XNJZFH08#YPSZxRlhHBGG

NOTE: You need to use a CPS version greater or equal the the 2025/01/26. See the CPS section viewtopic.php?f=12&t=4804

For translators, the on-screen texts, voice prompts CSV and CPS XML files are located at: https://drive.proton.me/urls/256SP2W1NM#mC9d2L32MEmb
The voice-prompts and localization files have not changed since the last beta.

This is not practical as it would consume too much program memory for the firmware to fit in radios like the RD5R, GD77 and DM1801.

All strings have to be the same length, otherwise its not possible to load different translated languages using the CPS to merge the firmware + additional / translated language, and additionally the string handling has to integrate with the VP system, so that when a specific string is used the VP can be indexed for it. etc
