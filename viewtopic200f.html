New OpenGD77 CPS 2024 10 31

Post by VK3KYY » Thu Oct 31, 2024 1:28 am

There is a new version of the OpenGD77 CPS available


downloads/PC_CPS/Latest

specifically

downloads/PC_CPS/Latest/OpenGD77CPSInst ... .31.01.exe

This version changes the "DMR ID" text on the Channel screen to show that this is an override to the Tx DMR ID.
Please note.
This setting should normally be empty, as its only used by people who have multiple DMR ID's and have specific reasons to use different DMR IDs on different channels.
You should NEVER enter the repeater DMR ID or anyone elses DMR ID into this box.


Also. The installer now waits for the COM driver to complete before continuing, as Windows 11 driver installation can take quite a long time, and its possible that the driver was not being fully installed becasue the CPS was not waiting for the driver installer bat file to complete

If you are updating the CPS from a previous version, there is normally no need to re-install the COM driver again, so you can uncheck that option in the installer. However re-installing never normally causes a problem


The CPS localisation files have also been updated, because of the addition line of text that has been added.
Speficially

This line

Code: Select all

<Control Id="lblOverrideTxDMRId" Text="Override Tx DMR ID" />
