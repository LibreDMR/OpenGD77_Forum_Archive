Thanks for the confirmation about the MDUV390. We thought it should work but you are the first to confirm that it does.
When displaying the GPS position you can transfer it to the radio's position page by pressing SK2 plus the up arrow key. This will set the radio's position and time for the satellite mode.

Part of the problem with the GPS is that TYT did not fit a backup battery to the GPS module. So it has to do a cold start every time it is turned on.

Post by G4EML » Thu Oct 13, 2022 6:10 pm

The recent changes in Eco modes appears to have triggered a know bug in some HRC6000 DMR Chips.
Some more testing shows that it can happen at any ECO level.

It can be reproduced in simplex mode. Set Eco 5. Wait 30 seconds so that the full eco power saving has started. Transmit with a second handheld, speaking quietly. If your chip has the bug the audio will probably be missing. Speak loudly and the audio will start again.

I think I have a fix for this. If it is successful it will be included in the next release.

Colin G4EML.
