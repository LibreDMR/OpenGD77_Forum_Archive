New cross-platform CPS software

  • Quote

Post by SA0ASM » Sat Jul 13, 2024 4:02 pm

Hi!

After being fed up with the state of the CPS code "inherited" from the Chinese manufacturers, I attempted to rectify the situation by writing my own from scratch. The initial feedback that I got was that people were really interested in getting it working cross-platform. So I had a go at something portable in .NET.

While I am no developer, I've managed to cobble together a new CPS codebase that now works across Windows, Linux and Mac using the Avalonia UI framework. This initial version reads and writes codeplugs from radios and can be used to edit all the usual contents such as channels, contacts, zones and groups. It can also import CSV files in the same format as the "official" CPS. Please give it a spin and let me know you get on in this thread!

Download link: https://1drv.ms/u/s!ArvAs24z8wEnhstqkP9 ... w?e=pqt3SM
Latest updated 2025-06-09, now requires .NET 8.0. Tested on Windows 10, Linux and Mac OS.

Post by SA0ASM » Sun Jul 21, 2024 1:49 pm

Please don't use Wine to run this software, it's intended to run natively in the dotnet framework.
Download and install dotnet 7.0 for Linux from here: https://dotnet.microsoft.com/en-us/download/dotnet/7.0
Then run the software using the "dotnet" commandline as stated above!

If the software can't find your radio, try selecting the correct serial port from the drop-down (click on "AUTO DETECT").
To help troubleshoot I would need the output of the "lsusb -v" and "dmesg |grep -2 ACM" commands to start...
