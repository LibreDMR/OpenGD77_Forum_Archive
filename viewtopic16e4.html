A new MD9600 beta version is now available

Changes in this version

• Increase number of nuisance entries during scan from 16 to 32
• Change Auto Power Off step size and maximum time
• Tx Inhibit
• (MD9600 only) Use battery RAM for settings, so that if power is removed from the radio the last change to settings / channel / vfo will be retained
• Handle if settings can’t be saved to Flash because of Write failure
• Added automatic roaming function, based on position e.g. from GPS or manual entry.
• Force re-sorting of channels in Roaming mode, my pressing the Enter button on the Roaming setting e.g Roaming:Manual
• (MD9600/UV380/DM1701/MD2017) Add option to display the time instead of the battery voltage or battery percentage (press and hold SK1 to display the battery voltage)
• Show distance to a repeater / channel when button 8 is held down (long press)

Thanks to Daniel F1RMB and to the pre-Beta testers

Romaing


The Roaming functionality supersedes the distance sorting functionality already in previous versions, by adding renaming this functionality and adding distance based options of 5km, 10km, and 20k.

Note. Distance sorting and hence Roaming does not work on the All Channels Zone because this is not a real zone, its actually just the full channels list.

When roaming is set to Manual, the current zone will be sorted by distance to each repeater, and the radio is automatically changed to the first channel in the sorted zone, i.e the closest repeater.

Also every time the Manual roaming option is selected, by pressing the Green button, the zone will be re-sorted.

In the distance based settings of 5km, 10km or 20km, when the position of the radio has changed by the specified distance, the channel list will be re-sorted by distance and the closest repeater selected again.

e.g. when driving, the zone list will be sorted every 5km , 10km or 20km of travel.

The zone will only be sorted during Rx, but will be sorted even if a signal is currently being received.

If a new channel is selected after the zone is sorted, there will be a short dropout of audio on both FM and also more dropout on DMR as the radio re-synchronises to the new DMR repeater.

If a new channel is selected, the radio will play the Alert beep and the display will illuminate.

Roaming is most useful for radio which have a GPS fitted, but if the position is entered manually, the zone will also be re-sorted if necessary.
Also, in order that the radio can calculate the distance to each repeater, the position Latitude / Longitude of each repeater needs to be entered into the CPS and the "Use location" checkbox need to be ticked.

Channels which don't have the location entered or don't have the Use location checkbox checked, are sorted to the bottom of the list and the distance can't be shown for these.


Generally to use roaming, its probably best to make a separate zone which contains all the linked repeaters and switch to that zone when using the roaming functionality

Long story

Originally, on both the MD9600 and RT3S, we used the battery RAM to store settings, but we found that the RAM battery would go flat after a few weeks of the radio not being used.

So we changed both the RT3S and MD9600 to use the Flash memory for settings storage.

This works fine on the RT3S because the settings can be trigged to save to Flash when the radio is turned off by the operator.

On the MD9600 this was not so satisfactorty, becasue although the settings are saved if the operator presses the power button to turn the radio off.

However because many people use the MD9600 in their car, connected via the 'ignition' or accessories circuit, which is only powered when the car is running, it was common for the power to be interrupted to the radio when the operator stopped the engine of the car, and the radio was then not saving the data to Flash.

So I changed the saving system on the MD9600, so that any changes to frequency , channels and options are almost immediatly written to the RAM, so that if the power is interrupted then the last change is not normally lost.

Also, when the radio is powered on, the firmware checks the contents of the Flash storage and if it is not up to date, then the settings from RAM are written to Flash

If the MD9600 is not used for a few weeks, and the internal backup battery goes flat, then when the radio is powered on, the RAM settings will be invalid, and the settings are instead loaded from Flash



I hope this explains how the changes to saving, now work on the MD9600
