  • Quote

Post by VK3KYY » Tue Nov 19, 2019 10:44 pm

Because of the rapid pace of development and because the Hotspot mode is mostly working in the Tier2 version, I've decided to rename the downloadable files

I've renamed the last Tier2Latest file to

OpenGD77_stable.sgl

and made a new file called

OpenGD77_latest.sgl

which now has the very latest changes which have not had much testing and could possibly crash etc, but have the latest features and bug fixes.

When I know that the OpenGD77_latest.sgl has had enough testing and is stable, I"ll copy that version to OpenGD77_stable.sgl

So the new location for the stable version is

https://github.com/rogerclarkmelbourne/ ... stable.sgl

and the very latest - not thoroughly tested version is here

https://github.com/rogerclarkmelbourne/ ... latest.sgl
