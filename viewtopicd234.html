If by backup you're referring to backing up the radio's factory flash settings, you can't do that until after you've upgraded the radio to OpenGD77 firmware.

At that point, you then need to store the resulting backup file in two or more safe places in case you ever want to revert to the factory firmware.

I didn't try to backup my radio until after installing OpenGD77 (as detailed in the upgrade instructions), but I'm pretty sure you won't see a COM port in the OpenGD77 CPS until the radio has been ungraded. Edit: I see you've already answered that question for yourself.

Post by VK3KYY » Mon Dec 30, 2024 9:46 pm

've reinstalled the CPS for the 390 and it installs without errors (even in event log) but there is no COM port
It'ts not clear what CPS you are taking about or what "event log" you are referring to.

If you are referring to the official TYT CPS for this radio, then the only thing you can backup is the calibration data, and you normally access this my holding Control-T in the official CPS

You can of course also read the official codeplug in the radio using the official CPS.

If you want to use your existing codeplug, the only way you can do this is if you can export the channels etc to CSV files using the official CPS, assuming it supports exporting to CSV. But AFIK there is no tool to directly convert from the official CPS CSV files to the OpenGD77CPS exported CSV format.


and like ZL2MGS says, the official CPS does not use a COM port. You will only see a COM port after installing the OpenGD77 firmware, and this COM port won't work with the official CPS, as it doesn't use that method.

Also. You can only install the OpenGD77 firmware using the OpenGD77CPS PC exe or the linux python script.

And.. The OpenGD77 firmware must be running for the OpenGD77CPS to communicate with the radio, i.e the radio must NOT be in DFU mode.

Post by SA0BUX » Mon Dec 30, 2024 9:50 pm

You can backup the original config first via the factory CPS, but this config can only be used with factory CPS.

The other backup is to backup the flash memory which contains data structures and config data for the factory firmware, this
backup is made as the first step after you have loaded OpenGD77 firmware but before you loaded any new config into the radio.

Normally the newly loaded OpenGD77 radio displays gibberish channel data in this step.

Radio should be powered on in normal mode (running OpenGD77) and then you go into Extras->OpenGD77 Support and click on "Backup Flash"

When you have saved the "Backup Flash" you can load a new codeplug from OpenGD77 which clears away the "gibberish"
