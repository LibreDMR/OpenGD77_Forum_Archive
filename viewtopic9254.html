A new MD-9600 RT-90 Beta is available


downloads/MD9600/Firmware/3e0614a2a8e60 ... 4547bcb982

downloads/MD9600/Firmware/Latest

This version changes the functionality of the Last Heard list

Pressing Enter (A/B) now changes the TG to the TG of the currently selected line
Pressing P1 + Enter (A/B) now sets the radio to make a private call to the station currently selected

Thanks to Daniel F1RMB for adding the new functionality
