OK.

You must also have reseleted the correct donor file. i.e the CPS makes a checksum of the 'donor' file you select and if it doesn't match the checksum of the correct donor file, then you'll get that message and you won't get DMR operation.


Also. Before you install the OpenGD77 firmware, the Only way to get the MD9600 into DFU mode is to hold the buttons in, and then attach the power cable.

Only after OpenGD77 is installed can you use the Power button and the P1 and Orange buttons to get the radio into DFU mode.
