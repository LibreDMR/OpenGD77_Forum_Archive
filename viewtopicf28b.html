MD380 / 390 is not supported becuase it uses an older DMR chip.

We did start porting the firmware to this radio and Colin G4EML got FM working, but then found that the older DMR chip didn't work like the newer chip in the other radios, and development then stopped.

Its not worth the time and effort attempt to port the firmware to radios which are no longer in production, when so may new radios are appearing which are still in production and can be supported

Supported handhelds are
TYT MD-UV380/390 (all versions including Plus and 10W) - GPS versions are also supported
Retevis RT-3S (this is a rebanded TYT MD-UV380)
Baofeng DM-1701/DM-1701B

The TYT / Retevis radio is better than the Baofeng, but its more expensive. The Baofeng also doesn't have a GPS option.

I am on the OpenGD77 facebook group, and people routinely get hung up UV380 vs UV390 flashing instructions since new users don't know UV380 refers to a "family" of radios including the RT-3S.

Often people say the CPS doesn't list UV390.. or they are asking where the UV390 firmware is since they can only find UV380. Can this be clarified somewhere, perhaps in the filename of the firmware and in the CPS? CPS currently says "MD-UV380 / RT-3S".

I understand their confusion, I had similar issues when I started using OpenGD77 - it comes from a fear of using the wrong firmware/process and bricking your radio - so its reassuring to see your specific model listed. It was already confusing that the donor firmware is for an entirely different mobile radio, but the reasons for doing so are spelled out in the instructions and the CPS looks for a specific filename, so this seems to be clearer to people.

Loading someone elses calibration file is generally not a good idea becuase the each individual radio has their own specific calibration paramaters which is set at the factory when they are originally tested and calibrated.


You can always restore the factory default calibration paramaters using the Calibration menu in the firmware. The firmware never adjusts these factory values as they are in a separate secure section of the Flash memory chip
