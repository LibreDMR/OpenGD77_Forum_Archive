You will need to go to the Calibration screen in the OpenGD77 firmware, and select the Factory Reset option, becuase when the firmware is first runs, it makes a copy of the offical calibration data and uses that copy so that the official calibration is never modified by the firmware

Probably the copy of the calibration data survived the official firmware being installed, and when you reloaded the OpenGD77 firmware, it used the existing copy of the data
