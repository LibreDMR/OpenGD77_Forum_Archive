 Hello, greetings everyone, here I leave you my version 4 theme for OpenGD77 with color screens.
This version is set with different day and night color themes, both in one file...
To configure the automatic mode from day to night, it is done from the device by activating the Options / Display Options menu / In this menu, activate the option, "Auto night: On".
Switch between day mode and night mode
Pressing and holding the SK1 button and touching the red button switches between day mode and night mode.
