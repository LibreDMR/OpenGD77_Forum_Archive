Post by F1RMB » Wed Apr 03, 2024 2:57 pm

You can't flash the OpenGD77 firmware with any other tool than the one we're providing (CPS (Windows onyl) or the python script).
It's not possible to make a backup of the MCU without flashing the OpenGD77 firmware first, hence no more genuine firmware.
It's not possible to get radio model while in bootloader mode. Simply, if you flash the wrong firmware, it will remain in bootloader mode (with Red/Green leds flashing).
The Flash backup feature is for the external flash chip, not the MCU. But you need to make a backup after you get the firmware installed, because there are few sensitive data that you maybe need in the futur (like if you want to get back to manufacturer firmware).
Also, make a backup of the calibration (same window in the OpenGD77 CPS).
