AFIK F4HWN has not posted details of the changes they made to the PWM frequency.

FYI.
Different radios seem to need different PWM rates in order to minimise any interference to the Tx audio.

There is no simple solution which works for all radios, because using a higher frequency causes problems with the backlight brightness on some radios; specifically the MD9600 / RT90 is very sensitive to PWM frequency and the optimum PWM frequency is different for each hardware version of this radio.

The DM1701 firmware build output is separate from the UV380/390 so it is possible to make a change specifically for this radio, however possibly there are different versions of DM1701 hardware which Baofeng does not publicise, and changing the PWM rate to fix a 'hum' problem on one users DM1701 may possibly cause the backlight to not work on another radio where the PWM components may not be identical
