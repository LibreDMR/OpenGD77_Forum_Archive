The problem with this display brightness on the 10W radios has been discussed extensively on this forum and IIRC is actually a hardware 'feature' on these radios, so that even with the official firmware the display is not as bright on the 10W radios as it is on the 5W radios.


You must however load the 10W compatible firmware, because the signal that turns backlight on / off is controlled from a different pin on the MCU/CPU. Hence why the 5W radio firmware won't work on the 10W radio.

There isn't a firmware fix that can make it any brighter.

The only way to mask the issue is to create a theme with colours that are higher contrast.

IMO the default black&white theme is probably already the highest contrast available, but you could try different contrasting colours
