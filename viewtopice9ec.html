Post by G4EML » Fri Nov 15, 2024 6:39 pm

First of all to check you are using the correct firmware test the radio on an FM simplex channel and make sure it receives and transmits. If it does then you are using the correct firmware. If it doesn't then try another version.

Regarding the talkgroup selection, that is probably a codeplug error or a misunderstanding of the way the firmware works. OpenGD77 normally uses one channel per repeater, selected with the knob. The talkgroup is then selected separately using the up and down buttons.

We would need to see a copy of your code plug to confirm this.

Post by G4EML » Sat Nov 16, 2024 12:22 pm

You can only have one TG List allocated to a channel. So in your case you could have three channels, one for Aylesbury, one for Tring, and one for West London. All three channels could be linked to the same TG List containing all of the DMR+ (Phoenix) talkgroups.

If you need to use a different TG list you would need to define a new channel that is linked to that list. So you may need Aylesbury A , Aylesbury B, and Aylesbury C.
