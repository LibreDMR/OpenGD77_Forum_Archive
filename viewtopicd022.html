Forum registration is now only if you have a callsign

Posted: Thu Dec 14, 2023 10:13 pm
by VK3KYY
Because of the massive problem we had with thousands of bots registering on the site, we had to manually cull about 2000 bot accounts in September &October 2023.

Following these deletions, all new account names must be people's registered callsign, which are verified against QRZ.com other reputable sources

Any registration which does not pass this test will be automatically deleted.

OpenGD77 is not the only forum which has needed to enforce registration rules, PiStar forum also seems to require callsigns.

I know this prevents non-Hams from registering on the site, but the site is fully accessible to everyone, unlike many social media groups which are private.

And despite it being clearly stated in the registration page, that you must enter a valid callsign, we continue to average 5 invalid callsign registration attempts per day
