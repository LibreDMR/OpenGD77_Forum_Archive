Did you use the OpenGD77 CPS "Restore Flash" for the restore ?

The procedure going back to factory firmware from OpenGD77 is:
1. Restore the flash backup via OpenGD77 CPS when still running OpenGD77
2. Start radio in DFU mode and use the factory firmware updater to load factory firmware.
