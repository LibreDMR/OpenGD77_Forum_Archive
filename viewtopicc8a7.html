Sounds like a hardware failure.

Bad external speaker jack, try with an external speaker. This is a known failure point.
Broken speaker cable or connector.
Bad connection on front panel ribbon cable.

Hi Colin,

Thanks for the prompt response !
I meanwhile found out that it is indeed a hardware failure. You're 100% correct.

When I plug in an external speaker, the audio is clear. No problem.
So most likely this is because of an open contact in the 3.5mm socket when nothing is plugged in.

As I've used this unit in my car for several years, with an external speaker, it looks like the spring contact inside the socket is no longer working properly.
