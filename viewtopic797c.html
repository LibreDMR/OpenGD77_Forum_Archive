linkford wrote: ↑
Thu May 26, 2022 7:03 am
 Where can i find the instructions to reverse the install of the open md-9600 back to factory. I have tried a few times, but I am missing something.
Assuming you backed up the Flash, you can restore it, and put back the origainal codeplug, and radio password etc etc

Then use the official loader to flash the official firmware. Note. If you don't load the exact official firmware for your radio hardware model, the Tx and Rx won't work, but the display and keypad etc will work.


If you didn't backup and then restore the flash, when you have loaded the official firmware you will probably get a message about a password.

To fix this you need to change a line in the official CPS setting.ini file from

password=0

to

password=password

Then reload your original codeplug

linkford wrote: ↑
Sun May 29, 2022 5:46 pm
 When i try to use the default loader for the default bin file it crashes about 5 seconds after starting, and the download never starts.
If the official firmware loader won't load the official firmware this is out of our control.


The way the firmware loading works, is that the radio has loader firmware installed by TYT at the factory, which is activated when you apply power to the radio while holding down P1 and Orange. This loader firmware is called the "bootloader".

The bootloader allows the main application firmware e.g. openMD9600 or the official firmware to be installed into the radio CPU either using the official loader or the OpenMD9600 loader

The OpenMD9600 loader exe can only load OpenMD9600 firmware and the official loader exe can only load the official firmware files.

Personally I found the official loader to be unreliable and would fail to upload or crash about 10% of the time.
But it sounds like the official loader is even worse for you.
