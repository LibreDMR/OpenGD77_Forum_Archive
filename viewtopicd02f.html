KB8YKF wrote: ↑
Fri Feb 02, 2024 2:53 am
 Are there instructions for upgrading from an older OpenGD77 to a newer one? I managed to upgrade properly by just putting it in DFU mode and upgrading, but I am missing settings I changed on the radio. Is there some step I missed?
Original installation is the same as an update except if no new settings got added between your last installed version and the new version, then it will just run straight away

If there were new settings, needed for new fuctionality e.g the whole new APRS beaconing functionality, then the existing settings need to be reset, and you'll need to press to acknowledge the settings have been updated, and you'll need to reselect the language.

Its also possible after updating the firmware you may need to update the codeplug in the radio from the version in the PC / CPS, because when we add new functions, e.g. Lat/Long location of repeaters, the data in the codeplug in the radio may contain random values , in this case that would be random Lat/Lon locations

It kinda depends when you last updated and also whether you updated to the latest CPS
