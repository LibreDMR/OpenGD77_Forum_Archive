Because of my mistake of not releasing the previous version with the ability to turn off the new, larger, font size there is now a new version, which adds the "Text size" option to display options, and also changes the default for Display "Info" back to its previous setting of "Off"

Text size : 1 = normal size
Text size : 2 = larger text for Channel name and VFO Rx frequency etc

No.

There are currently no developers active on this project.


IMO. Larger fonts are unlikely ever to be used on this project.

From the feedback on the forum, most people prefer the fonts at the existing size. These fonts are the correct size to display the maximum length channel or contact name etc, across the whole width of all displays.

Any unused vertical space on the UV380 is more likely to be used for other functionality.

None of the other radios have much ununsed screen area. Even the DM1701 has 8 pixels less vertical height, which limits any additional functionality, and the MD9600, GD77, DM1801 and RD5R have smaller screens.
