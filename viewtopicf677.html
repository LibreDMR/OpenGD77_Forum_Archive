Windows XP was never supported.

There has been no change to the installer except to add a password, which we had to add because of Google scanning the installer contents and falsely reporting that it was malware which resulted in Google blocking the download page(s)

Microsoft stopped supporting XP e.g. with security updates in 2014, so its not practical for us to support an OS version which was discontinued nearly 10 years ago
