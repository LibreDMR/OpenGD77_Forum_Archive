 Just updated to the aplpha 2.2 version and I cannot decrease the power.

Manual says "SK2+Left" decreases and "SK2+Right" increases power. Which is Right and which is Left ?

Read the initial post.

P1 = Left
P2 = Right

Don't hold down P1 or P2 when changing power. The functionality is designed to prevent accidental change in power caused by buttons being held in.
Holding P2 when on 5W has special functionality

See the USER GUIDE
But if you keep "P2" pressed at any power level it will go up to "+W+" (which is user defined power level).

This makes it confusing, since it should mean that keeping "P1" pressed should have the reverse effect.

Could not find an updated guide for MD2017, all I could find were the already supported models, where it says "SK1" and "SK2" which I tough that they were "P1" and "P2" respectively as it mapps easy in my brain.
The SK2+longpress P2 (or Right key on other platforms) is a safety measure, as the operator really insist to use higest DAC level for the PA drive.
Lowering power on the other hand don't need such safety thing, it works the same for all power levels.

About the user guide, the MD-2017 has only one reference at the moment. The firmware is in Alpha stage, and things could still change a lot, we can't waste time to write and rewrite multiple times various parts of the manual.
