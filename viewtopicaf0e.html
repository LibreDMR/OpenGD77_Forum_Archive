Hi, Like many I have been dissatisfied with the GPS performance. Based on some info in this post I have replaced the "Jumpstar JS-H210" module that came with the radio with an "ATGM336H-5N31" module. I did not change the antenna or any other components in the radio.

I'm now getting a cold start GPS position in about 45 seconds outdoors, which is a big improvement.

The module is a direct replacement.

Here is the Aliexpress link to the chip.
https://vi.aliexpress.com/item/10050069 ... pt=glo2vnm

I masked of the surrounding components with Kapton tape and used a hot air station to remove the chip old chip. Then some solder wick and alcohol to clean up the pads. Then soldered the new chip on.

Mike VK4MWL
