Just to be clear.

The V4 and V5 referred to on this site are our own version numbers based on our findings with the different TYT hardware. The version designations used internally by TYT themselves are not known and will almost certainly not be the same.

TYT have changed the synthesiser chips and the IF chips in these radios over the years. Different versions of firmware are needed for each chip change.
TYTs firmware identifies the chip types by the first digit of the version number.

TYT V06.xx is for early radios which we refer to as V1, V2 or V3 (All are essentially the same chipset)
TYT V16.xx is for mid production radios which we refer to as V4 (Change of synthesiser chip)
TYT V26.xx is for the latest radios which we refer to as V5 (Another change of synthesiser chip plus change of IF chip)

The CPU change from STM32 to the Clone chip does not need a different firmware version. (We did initially have an issue with this new CPU but this has now been fixed and all firmware versions now work with either CPU).

Colin G4EML
