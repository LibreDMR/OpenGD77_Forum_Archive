Post by VK3KYY » Tue Dec 03, 2019 3:02 am

As Alex has now done a fix for the keypad lockup, I've decided to update the "Latest" version on github

https://github.com/rogerclarkmelbourne/ ... latest.sgl

This should include all the various changes that have been going on in parallel for the last 2 or 3 weeks.

The only current omission is the Danish language support, as I still need to check it does not overflow the text buffers due to the lengths of the translated texts.

Note.

This version will allow Rx from 200Mhz - 260Mhz, and will transit if the Band Limits are turned off, however although it should be using the VHF calibration values for power and also for the DMR deviation etc, someone already reported that the power output on the 220Mhz band was very low, so there may be something wrong with the calibration for that band

There isnt any calibration data for that band, hence the code should be using the VHF calibration data (by design), however I think it should be possible to append another block of calibration data after the end of the existing calibration data block, possibly using the same structure as the UHF data, but I'd need to modify the CPS.
