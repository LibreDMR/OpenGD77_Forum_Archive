The URL on github changed some time ago. This is outside of our control, and possibly we should not include any default value for an alternative URL

When the registry key is deleted, and the CPS is run, the key will be recreated with the value hard coded into the CPS exe

Currently the URL is

https://raw.githubusercontent.com/Conta ... efault.csv

I just tested this the URL is still OK.

However, this may not be the cause of problems for everyone, as there are variations between the level of SSL support in different versions of the DotNet framework and also in each Windows installations, which often cause the download error
