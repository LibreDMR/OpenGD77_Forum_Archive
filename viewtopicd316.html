Post by VK3KYY » Sun Jul 07, 2024 7:34 am

All MD9600 use the same donor file

If you don't know how old the radio is, then you will need to try each version of OpenGD77 and see which version works with your radio

The display and controls will work for all radios even if you install the wrong version of OpenGD77, but the radio won't transmit or receive.

If the radio is not new, then its probably a V2 or possibly V1 radio

The only difference between V2 and V1 is the display dimming, and not many V1 radios were manufactured.

If V2 doesn't work, try the other versions
