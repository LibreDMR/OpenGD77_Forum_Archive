Post by VK3KYY » Fri Sep 27, 2024 9:54 pm

I had a look at the code, and there are problems

1. You have corrupted all the language files, with many special characters e.g. degree sign, and accent characters change to unvalid values. This applies to English and all other languages
2. You seem to have re-purposed the Japanese version, so that it would no longer be possible to build a Japanese version.
3. Your code assumes that the SECOND_LANGUAGE will be Chinese, and hence your new code would also run for French, German, Italian etc etc , and these languages won't display correctly
4. In the core display printing code, you don't check whether the langauge is Chinese, so I don't know whether even English would display correctly
5. Your Chinese font consumes all available program space, leaving no room for any more functionality to be added.
6. I don't think all Chinese users would accept only the limited font which you have used, i.e becuase it will fit in program ROM, i.e it will not display codeplug channel names etc correctly unless those codeplugs use a small subset of the total Chinese glyphs

So.

What you need to do is

1. Make a new build target for each supported platform.
In the build targets, copy each Japanese build target and rename that new build target to Chinese.
2. In the preprocessor settings, for both assembler and C, you need to change the setting which defines

LANGUAGE_BUILD_JAPANESE

and replace with

LANGUAGE_BUILD_CHINESE

In the code you need to use

#if defined(LANGUAGE_BUILD_CHINESE)
...
... Your new code here
...
#else
...
... normal version of code here
...
#endif

wrapper blocks around all your code


3. Remove all your RSSI code because its not directly related to Chinese and will also not fit on the non-chinese version of the UI


4. Revert the changes to all the language files

5. Copy HX8353E_charset_JA.h and rename to HX8353E_charset_CN.h and put your new font in this file

6. In file HX8353E_display.c

Change code to use Chinese font file for Chinese builds e.g.

Code: Select all

#if defined(LANGUAGE_BUILD_JAPANESE)
#include "hardware/HX8353E_charset_JA.h"
#elseif defined(LANGUAGE_BUILD_CHINESE)
#include "hardware/HX8353E_charset_CN.h"
#else
#include <hardware/HX8353E_charset.h>
#endif

7. There are probably more changes that are required but there were too many problems for me to remember them all

8. Rebuild all platforms and re-test for English, French, German, Japanese and Chinese versions



Overall however I think you also need to use Flash based storage of the font for the Chinese build, becuase with your changes, the code will no longer compile when I add the latest functionality that has been written after the last Stable release

You should consider whether using a RAM cache for some of the Chinese font would improve performance; but I do not know enough about the Chinese writing method to know whether some glyphs are used more than others and whether caching would improve performance, especially as there is also not much RAM space available
