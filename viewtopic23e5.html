New Beta version 2023 07 15

Post by VK3KYY » Sat Jul 15, 2023 7:47 am

A new Beta version is now available with some new functionality and various bug fixes

downloads/GD77/42a91ba8c79faafda13733eb2ca8cd0a00d49cdc

or

downloads/GD77/Latest

• Add “Night” theme system. This feature is primarily for colour radios e.g. UV380, a where separate Night theme can be uploaded.

On monochrome radios like the GD77 and MD9600, the Auto night theme is also available but because these radios do not have a colour display, this feature inverts the colour of the display. i.e During the night, the screen has a black background with white text.

Theme can automatically switch between day and night themes if Options -> Display options - > Auto night is enabled (On), and also the clock and location is set.
Automatic Day / Night switching uses the position of the sun to determine whether Day or Night theme should be used.

Day / Night theme can also be manually toggled
SK1 + Red toggles (overrides) Day/Night, and disables auto night/day
SK1 + longpress RED clears the override (and re-enable auto night/day)

Note. Automatic Day/Night theme switching is checked every 5 minutes.

• Added Night brightness. Options -> Display options -> Nite Bright. The night brightness value is used in conjunction with the Day / Night theme system, as described above.

• If a Quick Key is assigned to increase or decrease the normal brightness value; when the radio is in Night theme mode, the same Quick Key will change the Night Bright value, so that the brightness can be adjusted regardless of Day/Night theme mode.

• Fix "No Keys" beep option access when VP pack is not found in flash.

• Change text “Bandwidth” in the Channel details to “BW” because the text of Bandwidth was too long and caused cropping of the bandwidth unit (kHz).
Note. All translated text which was too long, has also been changed to “BW”

• Do not attempt to save the settings or VFO when Flash memory test has failed

• Fix reverseRepeater / displayChannelSetting / monitorMode in VFO

• Internal changes to the way the buttons/keys are detected for monitor mode.

• Add missing voice prompt, and update voice prompts to support the new functionality
See https://opengd77.com/downloads/Voice_Prompts/Latest

Thanks go to Daniel F1RMB, for creating all these fixes and enhancements

Probably you had some sort of glitch when the firmware file was being uploaded from your PC.

FYI.

The CPU in the radio has a way to latch the power to the radio, i.e a FET in parallel with the On/Off switch, so that turning off the switch does not guarantee that the radio is actually being turned off.

The reason the CPU needs this control is to allow the CPU to hold the power for a short while after you turn off the radio so that it can save the settings.

However, if something goes wrong with the upload, this override can remain on, and hence you have to take the battery out.
