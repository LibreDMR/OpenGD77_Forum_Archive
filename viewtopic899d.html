Possible bug on RD-5R on Power and Color Code.

Posted: Thu Mar 06, 2025 11:42 pm
by Nat
I wonder if anyone has noticed this strange behavior on the RD-5R:

Output Power:
in DMR you can't set it freely. When you scroll the power the values don't go in sequence, they jump, for example, from 1W to 4W to 2W. Also, going one step beyond 5W you get null>25.

Color Code:
although the color code is set to 1 in the codeplug, it shows a different code, usually 3. So when it receives a signal it takes some time to set it to the correct code.

Firmware Version: 20250223 but I have seen this behavior on previous versions too.

Note: I have same settings, same version and same codeplug installed on DM1801 without problems
