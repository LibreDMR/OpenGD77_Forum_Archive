Post by KA1CM » Thu Feb 13, 2025 11:08 pm

first of all, Please read the manual https://github.com/LibreDMR/OpenGD77_Us ... r_Guide.md

Secondly, Talk group 91 is very active, hence it is very hard to unlink. I assume your hot spot is a simplex hotspot. If you can hear anything that means your hotspot is transmitting, just like any other simplex transceivers, when it is in transmit it will not hear anything. to be able to key up on tK 4000 to unlink, you need to key in in the gab between the stations, just like if you were to break in.

another way to unlink is go to brandmeister website, login, then select My device on the left and remove 91 out of static Talk group.

Hope this help

Brandmeister also have a annoying "feature" Autostatic for simplex hotspots.

https://help.brandmeister.us/talk-group ... spots-only
Auto-static (Simplex Hotspots only)
A auto-static is for hotspots only and sets the hotspot to stay on the current active talk group which was activated by keying up the radio through the hotspot by the user. This means this talk group will stay active until the user on the hotspot keys up another talk group and of which will set the new talkgroup as the new auto-static.
Wish that this "feature" could be disabled via selfservice.
