Sorry, but it's not really clear.

AO-123 is already part of the satellites list.
But as a general safety usage, it would be better for you to keep your modified satellites.txt file in your Documents folder, and copy it to the OpenGD77 CPS installation folder after a software update. This way you can't lose your modifications.
BTW, as it already happened, double check the pristine satellites.txt file before dropping your modified version, as data structure can evolve.

The other trick (with the same content checking mentionned above) is to select a non-standard satellites.txt file. For this, in the "OpenGD77 support" window, hold down the Control key before clicking the "Install satellite keps" button. A file picker will appear, select your satellites.txt file (e.g located in your Documents folder).
The selected file will be stored as the default satellites.txt file, until it gets invalid or missing.
