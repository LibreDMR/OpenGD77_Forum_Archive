Post by WY7JT » Wed Sep 20, 2023 5:12 pm

I had some issues with the new CPS, which might have been due to VMWare which was running a Manjaro Linux desktop. It bricked my GD-77 with an error, and would error out when trying to update my database on the TYT MD-UV380. I closed down VMWare and rebooted. The firmware on the GD-77 loaded fine after I reselected the stock firmware and then a database update completed on the MD-UV380. I'll chock it down to Windows 10 weirdness, as things were working properly with assigning the USB port to the host verses guest. Consequently, I've never had issues using the CPS with a VMWare VM running at the same time.

I share in case someone has similar issues.
