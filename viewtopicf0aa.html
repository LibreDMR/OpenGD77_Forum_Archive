Is it a Brandmeister repeater ?
If you key up a talkgroup it's normally active for 15 minutes and if there is no local activity the dynamic talkgroup is removed from the repeater.

Some repeaters have some static talkgroups.

Most DMR systems have some sort of portal where you can see such things.

https://brandmeister.network/?page=repeaters
