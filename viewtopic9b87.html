Post by VK3KYY » Sat Sep 24, 2022 10:51 pm

VK3KYY wrote: ↑
Sat Sep 24, 2022 9:14 pm
 I did not notice this problem on my radio, but the problem will be the ADC input, which measures the volume control etc

I will try increasing the priority of the ADC interrupt input
Unfortunately, if I increase the ADC priority, I have the dropout problem again.

The intial problem seems to be that the Interrupt Service Routine (ISR), code which is triggered by hardware signals from the C6000 DMR chip, is not being run, because the CPU is busy

Increasing the priority of the C6000 interrupts, specifically the TimeSlot interrupt signal, fixed the dropout for me, and I did not notice the problem with the volume and on / off inputs.

At the moment, I don't know why the CPU not managing to perform all the tasks that it needs to, in order to receive DMR.

On the GD77, the CPU is operated at 3/4 its normally speed, which is 1/2 the speed of the UV380 CPU, yet the UV380 CPU is not fast enough somehow
