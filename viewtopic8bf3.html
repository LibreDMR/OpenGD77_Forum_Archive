  • Quote

Post by VK3KYY » Sat Apr 22, 2023 11:07 pm

A new Beta version is now available

You MUST use the latest CPS to install this firmware version

downloads/GD77/643b365e8d164db254d3159de553afa5d8e4c6c0

downloads/GD77/Latest

This version has a calibration screen with similar functionality to the UV380 calibration screen, in the Options menu
Becuase the GD77 screen is smaller than the UV380 screen, the calibration user interface has been split into multiple pages.
Use SK2 + Up / Down to navigate between pages
Also, note there are only 2 frequency calibration data points. 145Mhz and 435Mhz, this is actually the same as the UV380 version, except it was not clear on the UV380 version that there is not a frequency calibrarion data point per power setting calibration band.

It also has the Talkaround functionality, for repeater channels, which is being added to all firmware versions

Thanks to Daniel F1RMB for his work on this and the other firmwares
