New Alpha is available

downloads/MDUV380/Firmware/77bd96aeaa9e ... 914b82e8bd

This version fixes the bug on the Channel mode screen, Quick menu - Thanks to Colin G4EML

This version also has a new menu item in the General Options screen, to enable the GPS.
The GPS functionality has 3 settings
Off - GPS is always off unless you enter the GPS screen in the Radio Info screen
On - GPS is always on

'Start', this is a new feature which is currently being developed, where the GPS will operate until a GPS position fix has been received. However becuase I had to release the fix for the Channel screen, this feature is not fully functional at the moment.

If the radio has GPS and the GPS is turned on, 'GPS' will be displayed to the left of the battery voltage

When a GPS lock / fix is acheived, this text becomes bold, and the GPS position is automatically transferred to the location used by Satellite Mode etc and the internal clock is updated with the GPS time.

Note.
The GPS receiver constantly takes 50mA, so if you do not want to use GPS and see the GPS text displayed, please go into the General Options and change the GPS to "Off"
