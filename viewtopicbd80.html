On this one, I don't think it is UNNECESSARILY. Maybe the second or third one have changed position in the sorted list. I think it is great to always have a correct sorting order.
It will always sort the list when your location is greater than 5km etc from when it last sorted the list, so the second and third etc could change position in the list.

But it shouldn't reload the current channel if its not changed, but it does this in the last version I sent you

If you select any of the distance based roaming options, i.e 5km, 10km etc, then it will automatically keep selecting the closest repeater when it resorts.

i.e if you manualy change to the second channel; when it next sorts it will change back to the first channel in the lisy because its closer.

I had a think about whether in either manual or automatic / distance sorting, it should go back to the first channel, but I think this is probably the best options in both manual or auto / distance modes, as currently there is no indication of which position in the list is currently selected.
