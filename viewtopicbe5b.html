Uninstall the "Digital Radio in USB mode" device via the device manager, I suggest that you also tick the "Delete the driver software for this device".

Problem is that "Digital Radio in USB mode" driver match the same USB device id and outranks the older STM DFU driver.

On my Windows 11 laptop I have also disabled automatic driver update as Windows could reinstall the unwanted driver via Windows Update.
https://pureinfotech.com/disable-automa ... indows-11/
