Fn+S1 temporarily swaps VFO Rx for Tx in FM mode. Maybe it should be just Tx to Rx ?

Post by VK3KYY » Tue Aug 18, 2020 7:25 am

Probably best not to include things for SK2 + NUM KEY, as the long term plan is to make these user configurable.

We have a few SK2 + NUM, but these were experimental assignments

There is currently a PR to make these configurable, but they would get overwritten even time the codeplug is uploaded, which is not ideal

The optimum solution for SK2 + NUM requires big changes to the CPS, which I don't have time to undertake at the moment (and possibly never will have time)
