Thanks to the work of BD4VOW we are now developing a version of the firmware for the Baofeng DM-1701

It also looks likely that we will be able to develop a version which works on the TYT MD-2017 / Retevis RT-91

Currently the DM-1701 version still has some problems with the user interface keypad mapping, but we hope to improve this as soon as the DM-1701 which I ordered on 4th March arrives.

The latest firmware for the DM-1701 can be downloaded from here

downloads/DM1701/Firmware/Latest/


The CPS is already being modified to support loading firmware onto these radios.

See the version of the CPS with the newest date in downloads/CPS/Latest/
