Over the last few days I've been a helping out a friend of mine install Opengd77 on his TYT DM- 9600. He isn't too confident with computers so I offered to help out. He's now decided that he prefers the radio with Stock Firmware as he's used to it and gave me the rig back to return it so. This is when things start going pear shaped.
It appears that the backups that I took I had saved to a bad USB stick and I'm not able to retrieve any of the files from it. I've even brought it to the IT gurus in work who have super duper retrieval software and they can't retrieve the data.
To date I've tried to flash every version of software I can find with no success. The firmware flashes fine but the radio will not power on afterwards. Every time I can then reflash Opengd77 and it works fine again. To add mystery to the problem I can't decipher what hardware version the radio is. It's not printed on the main board. I've attached a picture for reference.
The tyt website download section has CPS software but no firmware listed and to date they are unresponsive to emails. Any help or guidance on this would be greatly appreciated.

How old is the radio? This would be clue to the possible hardware version

I don't know about the official firmware, but if you install the wrong version of OpenGD77 the radio will still boot up, but it won't transmit or receive

The official firmware however may not appear to be working as it may be getting confused with the OpenGD77 codeplug data, however I don't recall anyone reporting you symptoms.

Normally all that happens is that the radio asks for a pin code, and you have to reload an official codeplug into the radio to fix this.

Check if the official CPS is able to upload a codeplug.
Note to bypass the pin number think , IIRC you need to change the official CPS's .ini file and make sure the password entry is set to password
Google for the exact details of the .ini file thing



PS.

I find it hard to believe that someone would prefer the stock firmware, unless they need SMS
