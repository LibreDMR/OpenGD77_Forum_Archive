Post by VK3KYY » Tue Nov 19, 2019 10:46 am

Its on the To Do list to make this as flexible as the old hotpot mode, but I changed the way the power is handled in the Tier 2 version to be in steps and it was easier for me to get the hotspot working, to just calculate out the approximate step for each % power setting

The problem is really that the power curve is only relatively linear between 1W and 5W.

Below 1W the power curve is exponential.

To get the 250, 500 and 750mW settings relatively accurate, I subtract fixed values below the calibration PA drive value for 1W (where the raw value is normally around 1600 )

If someone could work out an equation of % power -> PA drive value, it would be great , as we could use it for the hotspot

BTW. I did consider adding some more power options e.g 50mW and also 5W+ (i.e drive the PA to the Max)
