Post by VK3KYY » Wed Aug 09, 2023 7:25 am

BTW.

I hoped to be able to use the official STM MCU API with the MCU in this radio, but looking in the data sheet, the DP32G030 far from an indentical clone of the STM32G030.
Both chips are ARM Cortex M0 and in the same physical package, but that seems to be the limit of the compatibility

The GPIO pins broken out to the package are different, the register base addresses are different. I've not looked to see if the GPIO pin control registers operate in the same way, or whether the other peripherals e.g. UART and I2C have similar register controls

And there is no information on the web about the DP32G030 apart from the datasheet / reference manual in one of the GitHub repos
