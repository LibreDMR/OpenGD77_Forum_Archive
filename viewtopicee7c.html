Hi,

Without its mic, the MD-9600 is almost unusable.
P3 button is currently not used, except at boot time, but it's reserved for futur possible usage. So it won't be some random QuickKey assignment.
You can use Quickkey with P1(SK2) + <number>, or using the SK2 latch from the mic.
The longpress ENT as Orange is there because some users has defective Orange button.
