Becasue of the problem with the FM 25kHz bandwidth frequency offset, I've done a temporary fix

See

downloads/MD2017/Firmware/d63265696e4f4 ... 8c9f3d684d

There appears to be a general problem in both the MD2017 and UV380/DM1701 etc codebases where the DMR+FM DSP chip is not being configured correctly, and in the case of the MD2017 its causing an additional frequency offset.

We are now investigating the problem on both the MD2017 and UV380.

Note. The UV380 version already has a 3kHz frequency correction factor, which should probably not be necessary

EDIT:
Some fixes/improvments:
- Trackball settings to make it more or less reactive (Off/Low/Fast).
- Supports external mic.
- Fixes some Flash write problems on shutdown.
- Fixes ECO mode.
- Some speed improvments.
- RSSI calibration updates (thanks to OH2FHJ).
- CustomData erase on startup (SK2+Down+Power On)
