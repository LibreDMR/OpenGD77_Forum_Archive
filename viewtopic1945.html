 On the original firmware, the boot screen says "Retevis GPS", and I do have access to a GPS menu. But it just says "Satellite UnLock" and "No GPSInfo".
Looks suspicious.
Did you let it outdoor, to make it able to acquire a GPS fix ?

As a reminder, the OpenGD77 firmware enable the GPS power at boot time, and the software check if some NMEA data are received from the GPS module. If nothing is received after a given time, the power line of the GPS module is turned off, and GPS mode is set to None.
The same process is repeated on every power cycle.
