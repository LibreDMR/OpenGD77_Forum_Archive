Yes. Any number from 16 - 50.

The reason this is adjustable, is that radios like the GD-77, RD-5R and DM-1801 have small memory and the total number of ID's that can fit in the memory is inversely proportional to the space consumed by each ID + Callsign text

So less characters = more ID's and vice verse
