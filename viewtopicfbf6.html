Note. The MD9600 original firmware is used as a donor file for the codec, it's not meant to be flashed at all. This is the case for all the STM32 based transceivers supported by the firmware.

I already told you that's the same procedure for all the STM32 based transceiver.
You have never read someone bricked their device flashing the OpenGD77 firmware, that never happen. The only thing that could happen is a wrong firmware get flashed and the device stays in bootloader mode, waiting for a correct firmware to be flashed. That's all.

The MD-9600/MD-UV3x0/RT-3S/DM-1701 are working the same, in firmware flashing point of view. Only the USB cable differs.

You have tons of video on YT about this topic. Don't expect me to take you by the hand to flash the firmware, there are enough Howtos and threads here, YT videos, etc, about this topic.

Sorry to be a bit harsh, but since you're an Ham Radio, it means you're a bit technical person, used to document yourself.
