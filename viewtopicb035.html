A new MD2017/RT82 Beta is now available

downloads/MD2017/Firmware/cc187f0e7b137 ... beeefde2f/

downloads/MD2017/Firmware/Latest

This version add double height text functionality, and uses the new double height text for the Channel name, VFO Rx frequency and other parts of the firmware.

This version also has a fix for the intermitten button and keypad key problem experienced by a few users. Thanks to HB9GNB for his investigations into this problem.

Also. The "Info" option, in Options -> Display Options, has been changed to default to "Both" so that more detailed information about the TS and Power level are displayed. This default setting has been changed because of the frequency confusion of operators about why the TS has either changed or not changed to the expected value.
This functionality is already documented in the User Guide https://github.com/LibreDMR/OpenGD77_Us ... de.md#info

and

https://github.com/LibreDMR/OpenGD77_Us ... -talkgroup

e.g.

If a TG has a TS override then the TS value will show as "cS1" or "cS2" meaning Contact defined Slot.

If the font for the TS is Bold, this indicates a manual override of the codeplug TS settings, be that the TS define by the Channel or the TG / Contact


Thanks to Daniel F1RMB for developing the double height text functionality and all the beta testers for testing this.

EDIT (f1rmb)
There are some missing updates:
  • Add ability to store current GPS position in channel's Lat/Lon.
    - On GPS featured devices, editing the Channel details Lat or Lon, longpress the STAR key will store current GPS position (if GPS is on, and fix acquired).
  • Add an option to disable any channel change (on Flash).
    - see "Locked: Off/On" in General options. When it's on, SK2 + Green don't write the changes to the flash.
  • Fix APRS position conversion.
    - In some case, the conversion to minutes goes wrong, and ambiguity can make it worse.
  • Fix DMTF entering and more:
    - it was impossible to enter DTMF sequences on MD-UV390/MD-2017/MD-9600.
    - A/B/C/D was unavailable in the numerical input.
    - Many problem while txing
    - it was impossible on most platform to navigate the contact (DMR/DTMF), from within Channel/VFO screen (no effect from Up/Down keys).
    - On MD-9600, While using the numerical input (DTMF), long press 'A' permits to exit that screen
