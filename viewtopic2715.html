Post by G4EML » Wed Sep 14, 2022 6:42 pm

Hello,

The GPS module is fitted in the front panel with its own antenna. You won't see any difference on the main board. There is no method of fitting an external antenna to the radio, although it would be possible to unplug the internal antenna and run a cable to outside.

If the radio has a GPS module fitted it should be automatically detected and an extra page will appear in the Radio Information menu. this is between the Location and Temperature screens and has the Title 'GPS', it shows the received position, received time, and the number of satellites in view.

The GPS receiver is not that sensitive, so will probably not work correctly indoors. However the page should still be displayed and will show incorrect position and time. When it shows a good position you can transfer that to the radio by long press D followed by B. That position will then be used in the satellite calculations.

The blinking indicator at the centre bottom of the display just indicates that there is more than one page of information available.
