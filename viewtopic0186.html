VHF issues

  • Quote

Post by KJ4BOL » Fri Apr 11, 2025 5:43 pm

I recently acquired a TYT MD-9600 thru an ebay auction that was an part of an estate sale. Unit was never used, still in all plastic, not even programmed.

I installed the Open9600 firmware and programmed both analog and DMR channels for use as it was to be installed in my personal vehicle.

On the VHF side, I am showing interference coming in on ANY VHF frequency. This is for both programmed channels and VFO mode.
I have also had reports that my transmission on VHF analog (VHF links to a UHF repeater) sounds like it is off frequency slightly. Receive on my end sounds flawless. For clarification, I do not have and diagnostic equipment at my disposal to check this as of this posting. And the reports come from others using the repeater and other links during that same time-frame including the repeater trustee. Another operator used and confirmed flawless operation of the link I was using.

The UHF side is fine. No interference showing and reports of my transmissions are excellent.

Any ideas? I've tried to open the calibration menu in software but I do not get a table shown to check any values.

Thanks in advance. 73's

Post by VK3KYY » Fri Apr 11, 2025 8:48 pm

This problem is unlikely to be related to the OpenGD77 firmware, however in these instances you should always confirm the radio works correct using the official firmware, so that you can return it if faulty

You can reinstall the official firmware, but make sure that you install the correct version for the hardware revision / version of the radio.

These radios have completely separate hardware, i.e PLL and PA and IF etc for VHF and UHF, so its completely possibly that UHF works but VHF doesn't

Re:Calibration
The CPS does not have calibration screens for any of the newer radios. It only does backup / save / restore.

The firmware has a calibration screen for all radios, which allow the frequency and power to be calibrated, but the problem you describe sounds like its more than something that could be fixed by fine tuning the frequency adjustment or power output.
