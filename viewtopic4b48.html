DMR ID in the channel setup in CPS is only used if you want to be identified by some other DMR ID for a specific channel.
Normally it's the DMR ID that you set under "DMR ID and Callsign" that is used as your own DMR ID.
It should never be the repeaters ID in that field, and it's normally blank for a hotspot channel too (unless you pretend to be someone else).

There are some help texts defined but not for that field ( Enable HelpView )
