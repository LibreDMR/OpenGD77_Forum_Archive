Hi Folks,

I am having issues updating a "Troublesome" GD77S ,,, Meaning basically that I have to resort back to the stock firmware (That is shocking anyway)

Steps Followed (Some truncation but steps accurate):

- Latest OpenGD77CPS Running
- Connect POWERED OFF GD77S via USB
- Place GD77S into Firmware Update Mode (Remove battery, Reinstall Battery, Press SK1 along with SK2 then power on device ... Green light appears)
- Enter CPS / Extras / Firmware Loader
--> Select Radio Button for GD77S (etc)
--> Push Select Official Donor File and select the "Component" From the GD77. All Successful.
--> Select "Select a file and update" --> Select the OpenGGD77 GD77S firmware file

All erases and flashes successfully.

- Power down and briefly remove battery.
- Reconnect Radio and Read Radio from CPS. Success/
- Select Extras / OpnGD77 Support
- Select "Write Voice Prompt" --? Select say any of the English AU Nicole Monochrome 1.5 VPR files and write this into radio
- Power Down Radio.

Final Step

- Power Radio on while pressing SK2

Radio is effectively bricked until one can eventually force the "Original" v1.3 firmware back onto it. i.e. power down for around 10 secs, Battery out, Battery back, then SK1 and SK2 power on and use original firmware loader techniques.

Any tips as to how to get the OpenGD77 firmware onto an working this hardware?

Is there earlier firmware, that works, that needs to be loaded first? The original firmware/CPS has some nasty bugs and I woud prefer to see the end of it !
