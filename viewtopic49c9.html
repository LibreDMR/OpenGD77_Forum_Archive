Bug fixes and font changes

  • Quote

Post by VK3KYY » Tue Nov 19, 2019 2:27 am

I've uploaded a new Tier2Latest to github with the following changes
  • More font modifications from Daniel
  • Bug fix from Alex when saving channels to the internal codeplug memory, caused by a previous change to increase the frequency resolution to 10Hz to allow the 6.25kHz frequency step to work correctly
  • Functionality by me (suggested by Alex), where changes to the Channel when reading the Channel from the VFO and also when changes are made on the Channel details screen, are saved to the codeplug memory, rather than only being temporary
  • Bug fix by me, for an unreported issue where changes made on the Channel Details screen would not have always been saved to the codeplug
    memory
  • Firmware info now shows the build time and date as well as the current git commit code. e.g. if the code is listed as a0ebbc7
    The associated commit on github would be
    https://github.com/rogerclarkmelbourne/ ... it/a0ebbc7
The User guide has also been updated with the functionality changes when reading the VFO into a Channel and also when you press the Green button on the Channel details screen, as well as details of the revised Firmware info screen
