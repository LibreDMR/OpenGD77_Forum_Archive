KB0PCH wrote: ↑
Thu Jan 18, 2024 8:34 am
 I noticed there's a new CSV feature called "Update location from CSV" but I can't seem to find any documentation on how this works. Do I just need to chill until the new feature is finished or is my Google-fu failing me and I'm just not seeing the note that explains how it works?
Documentation is not up to date, and actually the CPS does not have a User Guide

Information about this was probably posted when it was added to the CPS, but this function opens a CSV file which must have 3 columns

Channel Name,Lat,Lon

The Channel Name must match the name you assigned to the channel

i.e if your channels e.g. repeaters are named with the callsign of the repeater, then its possible to download the Repeater Book data containing the Lat/Lon position, then reformatting the spreadsheet to remove the other columns

However it only works if you name the Channel with the callsign or some other information which you can crossreference from Repeater Book or other sources

Personally I used the repeater callsigns for the channel names, but I know many people have their own system of naming, e.g. the town/city or perhaps mountain location, in which case this won't work unless you can build a spreadsheet which has names which match your channel names
