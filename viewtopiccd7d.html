@oh1cym

When the Radio is seen in DFU mode, then it it in "OS Update mode".
That is where you update the OS, or install OpenGD77 if on "Factory firmware" - That is done via the CPS program.

You will NOT see the Radio as a ComPort until you have succesfully converted the radio to OpenGD77.
And the Radio have exited the OS-Update mode (DFU mode)
