This question has been asked recently.

The OpenGD77 firmware does not have a separate GPS version. The firmware detects if the radio has a GPS.

Only the specific official 'donor' firmware can be used. This 'donor' firmware is effectively only to provide the codec. Technically the OpenGD77 replaces everything in the donor firmware apart from the codec.
