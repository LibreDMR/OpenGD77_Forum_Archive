This is a test version, that tries to fix the "silent DMR" problem that happens sometimes; e.g when
a QSO talker remains silent (I'm not talking about kerchunkers).


You MUST report to this thread if this fixes or not that specific problem.


This is based on the 2025/03/23 Beta version.


The firmwares are available at: link removed because it does not fix the problem
The voice prompts are available at: https://drive.proton.me/urls/CT7Y3QE8CC#ivbPuzbV8ty1

NOTE: You need to use a CPS version greater or equal the the 2025/03/23. See the CPS section viewforum.php?f=12

For translators, the on-screen texts, voice prompts CSV are located at: https://drive.proton.me/urls/AFEPKF84F4#2ltiJXlnndiy

Post by EU1AEQ » Mon Mar 24, 2025 7:55 pm

If we're discussing the absence and disruption of DMR modulation when receiving an incoming QSO, the evening testing revealed the following:

1. Sporadic dropouts are present.
2. Testing was conducted on two radios—RT3S and MD-UV380—the first with an STM processor, the second with a TYT processor. No difference was observed. A third control station, Kydera DR360, was also used.
3. A duplex hotspot with an MMDVM HS HAT was used. This issue only occurs in duplex mode.
4. Currently, there are no full-fledged DMR repeaters available for testing—only simplex and duplex hotspots.
5. Firmware version 23.03.2025 (non-test) did not change anything, same as version 16.03.2025. Audio dropouts remain random and unpredictable.
