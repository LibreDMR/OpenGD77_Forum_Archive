 1) How to record the adjusted parameters of the R3TS radio?
For example, I have three RT3S radios with OpenGD77 installed. After resetting a radio's settings, how can I import configuration parameters from a configured radio and write the parameter to the reset radio.
Is there a way to write radio configuration parameters with OpenGD77 using CPS and save to Codeplug?


There is a technical reason why settings are not loaded or saved by the CPS.
This is because different versions of the firmware have different settings memory configuations

Although a function could be written to backup and restore settings, it would fail as soon as new firmware was loaded with any changes to the settings data structure.
e.g. New features like GPS enable / disable in the UV380 require changes to the settings data storage.

Also different radios, have different settings structures because of their different hardware eg. MD9600/UV380/GD77/GD77S/DM1801 etc etc

So it would never be possible to backup from one type of radio and restore to another.
