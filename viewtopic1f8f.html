[HOWTO] Flash the OpenGD77 firmware (new procedure)

Posted: Thu Jul 22, 2021 7:38 pm
by F1RMB
This procedure is valid for all the supported transceivers, regardless of the brand and model.

You must use this installation procedure

  1. Install the latest CPS, available here
  2. Check installation instruction here
    you also have a dedicated button in the CPS's Firmware Loader window
    flash_instructions.png
  3. As described in the installation instructions, download to your computer the Radioditty official firmware (GD-77 Firmware V4.3.6 [Ham Version]).
  4. Unzip the downloaded zip archive, then copy, somewhere on your hardrive (e.g. "My Documents"), the file GD-77_V4.3.6.sgl, located in "Firmware software V4.3.6\" sub-directory.
    • This file has to remain in that location, as it will be re-used the next time you will flash another OpenGD77 firmware file.
  5. Start the CPS
  6. In "Extras" menu, click on "Firmware loader" entry.
  7. Click the "Select Firmware v4.3.6" button.
    01-select_official_FW_button.png
  8. A file selection window will pop-up. Go to the location where you saved the GD-77_V4.3.6.sgl file, select it, click the "Open" button.
    02-select_official_FW_file.png
  9. The software will check the SGL file validity, a "[+DMR]" text is now displayed in the Firmware Loader window title.
    03-official_FW_validated.png
  10. Turn on your transceiver in bootloader mode (SK1 + SK2 + power on).
    • The Green led lit up, the screen remains off (or black).
  11. Select the correct radio model.
  12. Now click on the "Select a File & Update" button,
    04-Select_a_bin_file.png
  13. A file selection window will pop-up, go and select the OpenGD77 firmware you want to flash (a .bin file).
  14. The flashing procedure will start right after the OpenGD77 firmware file is selected.


Note: The next time you need to flash an OpenGD77 firmware, directly jump to 10.
