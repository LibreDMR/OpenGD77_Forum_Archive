Hi,

Have you checked if both SK keys are working ?

Otherwise, it smells like the security bytes were corrupted, like after a factory reset with some genuine firmwares.

You will need to flash a new bootloader, using a JLink (like EDU mini) hardware programmer.
Search the forum, there are posts about this.
