After select the donor file ( GD-77_V4.3.6.sgl ) you have to select the openGD77 firmware

The latest firmware downloads/GD77/Firmware/3ed4d3301fb6fb8 ... enGD77.zip

Before click on the openGD77 firmware by click on “select a file and update”. Make sure your radio is connected to the computer. Press and hold PTT and the button right below it while turning it on. Then select the firmware. Now you should see the flashing begin.

Hope this helps,

The donor file is never loaded to the radio. You simply need to have it available on your computer for use by the firmware loader. Once you register it's presence you will not see it again,

As Charlie says the file you load to the radio is the .zip file.
