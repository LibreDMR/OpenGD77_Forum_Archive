In addition to what Colin has written

The firmware display font is 8 bit, so only a limited subset of characters are allowed.

The font / character set is based on ASCII with special mapping to allow some accented and non-latin characters to be supported, but in general you should avoid any characters apart from A-Z a-z 0-9 and space
The full character set mapping is complicated and if you really need the full data on this, you would need to download the last source code release for any supported radio and look For Example in the UV380 code, at /application/include/HX9535E_charset.h
