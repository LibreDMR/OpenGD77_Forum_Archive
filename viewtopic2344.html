I recently spent some time looking at the Chinese localization code of BA7IQE, and was deeply inspired. In response to the problem that BA7IQE made custom modifications to the original code and could not merge the code into the official code base, I made a version that only provides Chinese support to minimize the impact on the use of other languages, including Japanese, and removed the Chinese input method (I think it is more convenient to input in CPS). The current font file occupies the last 128KB of data in the external flash memory, but since I don't understand other series of hardware and don't have corresponding devices, I can't port it to other devices supported by OpenGD77. If this can be merged into the official code base, I will optimize the code I have implemented and try to add Japanese support (the font used by BA7IQE removes the Japanese Katakana included in GB2312), and make some contributions to the final merging of the Chinese version into the official library.
Thank you for the reply and test, the meaning of releasing the source code is that you can modify your favorite personal version and have fun.
