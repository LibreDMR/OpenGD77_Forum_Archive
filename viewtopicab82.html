New OpenGD77 CPS 2025 02 23

Post by F1RMB » Sun Feb 23, 2025 4:32 pm

  • Updated satellite.txt file from David, N9KT.
    See viewtopic.php?f=7&t=4904&p=35884#p35883
    To have POEM 4 TLE, url's GROUP has to be set to "active" instead of "amateur".
  • Fix the keps download URL storage/retrieval.
    Clicking CTRL+ALT while clicking the "install satellite keps" button restores the default URL.
    Also, if the keps download fails, the default keps URL is restored.
The installer can be downloaded from: https://drive.proton.me/urls/43E0Z20PAR#63ZowszjWAa4

NOTE: you need a firmware greater or equal to the 2025/01/26 to be able to use the Beacon Silently option.
For translators, CPS XML files are located at: https://drive.proton.me/urls/K6NBA7FRH0#owtc56LE34hj
