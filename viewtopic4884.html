New Beta 2023 11 19

Post by VK3KYY » Sun Nov 19, 2023 9:53 pm

A new Beta is available for the GD77/DM1801/RD5R/RD77S

See

downloads/GD77/Firmware/Latest


Changes since the last Beta release are

Firmware:
  • VOX bugfixes.
  • Don't trigger the vox when VP is playing.
  • Various languages updates.
  • GPS support added on all platforms except the GD-77S and RD5R.
  • GPS NMEA logging added (optional). GD-77S and RD5R are excluded here.
    • NMEA log clearing at boot time (SK1 + 5).
    • using Logging on < 16Mb devices disable the DMDId feature (cleared).
  • APRS beaconing added (Channel/VFO/Satellite).
    • please refer to the user guide for details.
  • Satellite: Voice/APRS/CW Rx modes added..
  • Show/Sort distance to repeater feature added.
  • VP updated.
  • Fix menu system bug (cancelation/validation on Options ones).
  • Fix problems with CPS communication when the GPS NMEA output is enabled.
  • Fix a CWID bug in the hotspot mode.
  • Adds Auto Lock options (see the user guide).
  • Various bugfixes.

This version features the APRS beacon functionality described in this post viewtopic.php?f=16&t=3352&start=10#p26717

Thanks to Daniel F1RMB for the majority of these new features and bug fixes and to Colin G4EML for the fix to the 1750Hz tone generation improvement.

The User Guide will be fully updated to document all the new features soon.


Note.

Existing voice prompt files do not work with this version. The latest new versions can be downloaded from here
downloads/Voice_Prompts/Latest

Also the functionality to read and write the calibration data requires the latest CPS, which can be downloaded from here

downloads/PC_CPS/Latest
