New MD-UV380/RT-3S/DM-1701/RT-84 Beta version 2025 01 26

Post by F1RMB » Sun Jan 26, 2025 9:19 am

  • Add APRS's Beaconing Silently flag support:
    • when it's enabled, the FSK tones won't be heard on the transceiver (no effect on the MD-9600/DM-1701, as they're always silent).
  • Support manual beaconing (SK1 + 2) in all APRS modes, except for PTT mode.
  • Fix some display glitches when APRS beaconing is triggered while in DIGITAL mode:
    • Transmission state is hidden the update screen functions.
  • Fix some last talker logics.
  • Fix Satellite Voice/APRS/CW Rx toggling (immediate recomputation, avoiding transmission problems).
  • When a beacon is transmitted, the "a" header flag is using the Counter colour.
The firmwares are available at: https://drive.proton.me/urls/M1N37CF9QG#s3utf9rgnfwd
The voice prompts are available at: https://drive.proton.me/urls/H0XNJZFH08#YPSZxRlhHBGG

NOTE: You need to use a CPS version greater or equal the the 2025/01/26. See the CPS section viewtopic.php?f=12&t=4804

For translators, the on-screen texts, voice prompts CSV and CPS XML files are located at: https://drive.proton.me/urls/256SP2W1NM#mC9d2L32MEmb
