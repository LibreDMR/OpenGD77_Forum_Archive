Impossible to install OPENGD77 in Baofeng DM-1701A

Posted: Wed Jul 02, 2025 10:57 pm
by EA7LIP
Hello. I have a Baofeng DM-1701A with firmware version V002.006 and CP version V01.05. It's completely impossible to install OPENGD77. The original Baofeng CPS recognizes the radio and I can program it without any problems, but the OPENGD77 CPS doesn't detect the radio—it's impossible to access it. Could it be that my current firmware is incompatible with OPENGD77? In both cases, I have used the same cable and the same USB port. Can someone help me? Thank you very much.

Re: Impossible to install OPENGD77 in Baofeng DM-1701A

Posted: Wed Jul 02, 2025 11:33 pm
by MELERIX
first the radio must be in DFU mode in order to flash the OpenGD77 (also STM DFU Driver must be installed) and after that, the radio must be in normal model to be detected by OpenGD77 CPS for programming.
