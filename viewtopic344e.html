oh2fhj wrote: ↑
Tue Feb 06, 2024 6:40 am
 I think the lockup happend only before I write the codeplug to the radio and fixt it self after that.
I wrote in the installation instructions

"If you use OpenGD77 on another radio, you can use the same codeplug with the MD2017, so simply upload the codeplug to the radio

If you don't have an OpenGD77 codeplug, you will need to make a basic codeplug, by entering your DMR ID and callsign into the CPS, and optionally setup some channels and then upload that codeplug to the radio"


Before you load an OpenGD77 codeplug the radio is full of unknown official firmware data, which the OpenGD77 firmware is unable to read and WILL cause errors and possibly crash if you attempt to do anything with the radio.
