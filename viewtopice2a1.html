SA0BUX wrote: ↑
Mon Jan 20, 2025 8:01 pm
Some questions about the changed APRS function.

The APRS profile where I defined 144.800 (European APRS freq) should be added to all channels where I want periodic APRS reports ?
Depends of what you want to do.
If you only to send beacon on the 144.800MHz, then yes, the APRS config need to have the TX Frequency set to that frequency,

SA0BUX wrote: ↑
Mon Jan 20, 2025 8:01 pm
 And APRS should be Auto or Smart ?, does it work with Manual or PTT too ?
It works as before. The APRS configuration is handled the same, regardless of the APRS settings.
The PTT mode don't change the frequency, as the point of this mode is to send a beacon when releasing the PTT, on the same frequency.
About the beaconing mode selection, it's up to you.

SA0BUX wrote: ↑
Mon Jan 20, 2025 8:01 pm
 What about TX power ?, I'm not sure but it seems that it use the same as the master power or the setting on the channel ?
It uses the channel power setting.

SA0BUX wrote: ↑
Mon Jan 20, 2025 8:01 pm
 Does it work during scan or only when you are on a channel ?
Dual-Watch ?
As before, there is no APRS beaconing while scanning.

One small bug to report. TYT MD-UV380. After installing the firmware (this occurred on multiple radios of the same model), the "Last Talker" setting under "Display Options" is set to 255. The maximum intended value for this setting seems to be 30.

If a user reduces the value from 255, the user cannot increase it until they get to 29. At that point, the value can be increased to 30 and will not go above 30.
