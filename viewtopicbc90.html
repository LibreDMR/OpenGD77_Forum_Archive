Post by VK3KYY » Thu Feb 15, 2024 7:23 am

An Alpha 2.0 version is now available to download

downloads/MD2017/Firmware/faf54d394a2ac ... 0aad53cf4d


EDIT.

Use this updated version V2.2

downloads/MD2017/Firmware/d63265696e4f4 ... 8c9f3d684d



This version has trackball support. Thanks to Daniel F1RMB.
Trackball functionality is off by default, becuase many trackballs in these radios are faulty and can generate spurious inputs.
To enable the Trackball, see Options -> General Options -> Trackball.


RSSI on VHF have been rescaled, using data supplied by OH2FHJ
Satellite mode DTMF bug (applicable to all OpenGD77 versions) has been fixed. Thanks to Daniel F1RMB

Increased audio levels on DMR and FM
Change to FM audio filter paramaters to match official firmware.
Bug fix to external mic input. No change to operation.

Experimental dual RSSI display
MD2017_dual_RSSI.png (3.24 KiB) Viewed 11884 times
RSSI at the top of the screen is the active VFO freq
RSSI at the bottom of the screen is the inactive VFO freq

When channel mode is selected the RSSI at the top will be the current channel and the RSSI at the bottom will continue to be the inactive VFO

This is a work in progress for debug purposes to help test additional features that may be added to the firmware for this radio

Note.

This version does not fix the keypad problem experienced by some people

I only know 2 people who have the version of the radio which has the keypad problem, and neither of them have used the Debug Mode features in the Alpha version, which would give me more information about why the keypad appears not to work in these radios.

Its possible the problem is not the keypad and that the firmware is actually crashing / hanging on these radios.
But until someone with one of these radios has time to use Debug Mode, its impossible to make any progress with this problem
