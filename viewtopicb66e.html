Hello.


I’ve been manually saving repeaters to my GD77 while driving around, checking availability via RepeaterBook. Over time, this has resulted in an unstructured and chaotic list of stored repeaters, making navigation increasingly difficult.

I recently discovered that the CPS software supports importing and exporting channel data in CSV format. Since I’m quite proficient with Excel and LibreOffice Calc, this seems like a good way to properly organize my channels. Additionally, as I am blind, I find the built-in CPS organizational functions somewhat cumbersome to use.

My goals are:
- Creating zones
- Moving channels into zones
- Changing the order of channels

Before I proceed, I have some specific questions regarding the CSV workflow:
- What should I keep in mind when working with the exported CSV files?
- What delimiter does CPS use—comma, semicolon, or tab (TSV format)?
- Are frequency values stored with a decimal point or comma? In Germany, we use a comma as the decimal separator and a period as a thousands separator, which could cause issues.
- When editing the CSV, can I assign a channel to a zone that does not yet exist in CPS, or must I first create the zone within CPS before referencing it in the file?

Any insights or best practices would be greatly appreciated!

73s,
Richard, DO9RE

When moving channels in channels.csv you must copy the entire row of data and make sure the columns remain aligned. If creating a new channel it is best to copy the row of a similar channel and then make changes to the columns as needed. Always ensure the channel number column is unique. Two channels with the same channel number will overwrite each other. Channel numbers don't have to be sequential (they can have gaps) but they must be unique.

The CPS should automatically cope with commas or periods based on the windows country settings. It also scans input lines and tries to identify the format automatically.

Yes, you can create new zones and add channels to them, just add an extra line to zones.csv and make sure the channel names in the columns are exactly the same as those defined in channels.csv.

Internally the Code plug uses index numbers to refer to channels, zones, contacts etc.
The CSV builds these indexes from the names used in the CSV files using exact matching. So it is important that the names are exactly the same wherever they are used.

Colin G4EML
