New MD-UV380/RT-3S/DM-1701/RT-84 Beta version 2025 03 23.

  • Quote

Post by F1RMB » Sun Mar 23, 2025 5:55 am

  • Reapply CSS RX once the DTMF sequence has ended.
  • Take care of RD5R display buffer height (48 vs 64 on MK22 platforms).
  • Screengrabber Python script takes care of RD5R screen size too.
    • available at https://drive.proton.me/urls/K2TF5ZCQJ8#NhIcfp2oKy0R.
  • Add GPS support for RD5R platform.
    • NOTE: the RSSI screen doesn't display the sat's number, as there is no room for this on screen.
The firmwares are available at: https://drive.proton.me/urls/Q1FEHX8N5G#Ws1ZHkUjl29w
The voice prompts are available at: https://drive.proton.me/urls/CT7Y3QE8CC#ivbPuzbV8ty1

NOTE: You need to use a CPS version greater or equal the the 2025/03/23. See the CPS section viewforum.php?f=12

For translators, the on-screen texts, voice prompts CSV are located at: https://drive.proton.me/urls/AFEPKF84F4#2ltiJXlnndiy

Hi. I have exactly the same issue if I set the DMR Rx AGC to 3dB or more. The issue is stronger the higher the dB value is set. This applies to reception.The issue can be reproduced: while listening to a communication in progress on the repeater, go into Menu/Options/Sound Options and change the DMR Rx AGC: from off to 6 dB.
Often, simply entering the menu is sufficient. (but there must always be DMR Rx AGC increased)
On the home screen this also occurs but only sometimes.
RT3S SN 2202R03S11xxxxx STM CPU.
EDIT:I've just noticed that there may be a link to “Prompt: Beep”. When it is "Prompt: Silent" the problem does not seem to occur.
